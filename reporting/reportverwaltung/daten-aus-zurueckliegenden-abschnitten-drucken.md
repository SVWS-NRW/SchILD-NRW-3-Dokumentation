# Daten aus zurückliegenden Abschnitten drucken

Mit der Reportverwaltung können Sie Daten eines früheren Lernabschnitts ausgeben. Standardmäßig verwendet der Reportexplorer den aktuellen Abschnitt.

## Wann ist ein früherer Abschnitt erforderlich?

Typische Fälle sind:

- Sie benötigen eine Leistungsübersicht aus einem früheren Lernabschnitt.
- Sie müssen ein Abgangszeugnis für das alte Halbjahr erstellen.
- Die Schule wurde vor dem Zeugnisdruck bereits in den nächsten Abschnitt versetzt.

## Den Lernabschnitt wählen

[![Wahl eines vergangenen Lernabschnitts](/bilder/reportverwaltung/reports-grundlagen-16-vergangene-abschnitte.png)](/bilder/reportverwaltung/reports-grundlagen-16-vergangene-abschnitte.png)

*Wahl eines vergangenen Lernabschnitts*

1. Öffnen Sie die Reportverwaltung.
2. Wählen Sie im Dropdown-Menü **Jahr** den gewünschten früheren Abschnitt.
3. Rufen Sie den benötigten Report auf und kontrollieren Sie die Ausgabe für diesen Abschnitt.

::: warning Wichtig – Anschließend den aktuellen Abschnitt einstellen
Stellen Sie nach der Ausgabe wieder auf den aktuellen Abschnitt zurück. Sonst können auch nachfolgende Reports Daten des früheren Abschnitts verwenden.
:::

Die Auswahl des Abschnitts und das Zurückstellen sind auch im [Menüband der Reportverwaltung](/reporting/reportverwaltung/menueband-reportverwaltung) beschrieben.
