# Reports erstellen und anpassen

Gestalten Sie einen Report auf Grundlage einer vorhandenen Vorlage oder erstellen Sie eine neue Liste. Beginnen Sie mit einer einfachen Ausgabe und kontrollieren Sie Änderungen regelmäßig in der Vorschau.

## Den passenden Einstieg wählen

- Den Aufbau verstehen: [Wie ein Report Daten zu einer Ausgabe zusammenführt](/reporting/reportdesigner/was-leistet-ein-report-in-schild-nrw-3) und [Den Reportdesigner öffnen und verwenden](/reporting/reportdesigner/reportdesigner).
- Eine vorhandene Vorlage verändern: [Einen vorhandenen Report anpassen](/reporting/reportdesigner/einen-vorhandenen-report-anpassen).
- Eine neue Liste mit Unterstützung erstellen: [Einen Report mit dem Berichtsassistenten erstellen](/reporting/reportdesigner/einen-neuen-report-mit-dem-berichtsassistenten-erstellen).
- Den Report von Grund auf aufbauen: [Einen Report ohne Assistenten erstellen](/reporting/reportdesigner/neuen-report-erstellen).

## Eine Vorlage bearbeiten

1. Öffnen Sie die Vorlage in der Reportverwaltung über **Report bearbeiten**.
2. Passen Sie im **Entwurf** Schrift, Anordnung und Datenfelder an. Die [Anleitung zur Schulbescheinigung](/reporting/reportdesigner/einen-vorhandenen-report-anpassen) zeigt ein vollständiges Beispiel.
3. Kontrollieren Sie die Ausgabe über **Vorschau**.
4. Speichern Sie eine eigene Fassung unter einem eigenen Dateinamen. So wird sie beim Aktualisieren der Basisreports nicht durch eine gleichnamige Paketdatei ersetzt.

- Schriftarten und Sonderzeichen in einer PDF-Ausgabe erhalten: [Schriftarten und Sonderzeichen in PDF-Ausgaben](/reporting/reportdesigner/probleme-mit-fehlenden-schriftarten-im-pdf-dokument-tutorial).
