# Reports programmieren und erweitern

Prüfen Sie zunächst, ob Datenfelder, Gruppierungen oder Systemvariablen die gewünschte Aufgabe ohne Code lösen. Für weitergehende Anforderungen stehen Object Pascal, eigene Datenquellen und Subreports zur Verfügung.

## Den Erweiterungsweg wählen

| Anforderung | Anleitung |
| --- | --- |
| Ausgabe abhängig von einem Datenfeld steuern | [Reports mit Object Pascal erweitern](/reporting/programmierung/programmierung-in-reports) |
| Zusätzliche Daten mit SQL bereitstellen | [Eigene Datenquellen für Reports definieren](/reporting/programmierung/eigene-datenquellen) |
| Einen gemeinsamen Schulkopf nachladen | [Einen Subreport dynamisch einbinden](/reporting/programmierung/einen-subreport-dynamisch-in-einen-report-einbinden) |
| Eine vorhandene Funktion nachschlagen | [RAP-Funktionsreferenz](/reporting/rap) |

## Änderungen kontrollieren

Testen Sie die Ausgabe mit passenden Schülergruppen und den im jeweiligen Artikel beschriebenen Sonderfällen. Änderungen an einem dynamisch geladenen Subreport können sich auf mehrere Reports auswirken; prüfen Sie dabei auch Höhe und Layout.

Die [Übersicht zu Programmieraufgaben](/reporting/programmierung/programmierung-sonderlogik-themenuebersicht) verbindet die weiterführenden Anleitungen. Für allgemeine Regeln verwenden Sie [Reports übersichtlich und wartbar gestalten](/reporting/basisreports/basisreportsammlung-designrichtlinien).
