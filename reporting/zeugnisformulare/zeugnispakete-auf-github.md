# Zeugnispakete nach Schulform auswählen

Wählen Sie das Paket für Ihre Schulform. Jede Veröffentlichung enthält eine Änderungshistorie, anhand derer Sie den bereitgestellten Stand beurteilen können.

## Zeugnispakete auf GitHub

Für SchILD-NRW 3 werden alle Zeugnisse als ZIP-Paketdatei auf GitHub angeboten. Sie finden die Zeugnispakete im jeweiligen schulformspezifischen Release-Bereich. Zu jeder Veröffentlichung (Release) finden Sie dort auch eine Änderungshistorie anhand derer Sie entscheiden können, ob sich ein Download für Ihre Schulform lohnt.

## Links zu den Zeugnispaketen auf GitHub

- ➡️ [Zeugnisse - Primarstufe](<https://github.com/SVWS-NRW/Schild-NRW-3-Zeugnisse-GS/releases>)

Textzeugnis mit Floskeln, Noten-, Hybrid- und Ankreuzzeugnis, Lernstandsbericht für die Primarstufe

- ➡️ Zeugnisse - Sekundarstufe I (im Aufbau)

Zeugnisse, Abschluss-, Abgangs-, Überweisungs- und Inklusionszeugnisse, Lernstandsberichte für alle Schulformen der Sekundarstufe I

- ➡️ Zeugnisse - Sekundarstufe II (im Aufbau)

Zeugnis EF, Laufbahnbescheinigung, Abiturzeugnis und Bescheinigungen für die Sekundarstufe II

- ➡️ [Zeugnisse - Berufskolleg](<https://github.com/SVWS-NRW/Schild-NRW-3-Zeugnisse-BK/releases>)

Zeugnisse für alle Gliederungen von Anlage A bis Anlage E für Berufskollegs

- ➡️ [Zeugnisse - Weiterbildungskolleg](<https://github.com/SVWS-NRW/Schild-NRW-3-Zeugnisse-GS/releases>)

Zeugnis, Abgangs- und Abschlusszeugnis, Bescheinigungen für Weiterbildungskollegs
