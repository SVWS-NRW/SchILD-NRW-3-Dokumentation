# Basisreports auswählen und verwenden

Die Basisreportsammlung enthält Vorlagen für häufige Aufgaben. Finden Sie hier den passenden Zugang zu Downloads, Serienbriefen, Leistungsübersichten und Aufnahmebögen.

[Den passenden Einstieg in den Reportdesigner finden](/reporting/reportdesigner/reportdesigner-schnelleinstieg)

## Basisreports und Downloads

Mit der Installation von SchILD-NRW 3 wird eine Basisreportsammlung einmalig im SVWS-Arbeitsverzeichnis hinterlegt. Sie enthält Reports für typische Bedarfe in der Schule und folgt einer konsequenten Designrichtlinie. Die Sammlung ist ein guter Ausgangspunkt, um eigene Varianten eines Reports zu erstellen.

::: info Hinweis – Download

[Laden Sie über diesen Link die neuste Version der Basisreportsammlung auf GitHub herunter.](<https://github.com/SVWS-NRW/Schild-NRW-3-Reports/releases>)

:::

Die Basisreportsammlung wird bei der Erstinstallation von SchILD-NRW 3 im SVWS-Arbeitsverzeichnis abgelegt. Sie wird bei Updates nicht automatisch aktualisiert. Im Release-Bereich auf GitHub wächst sie jedoch stetig weiter. Sie können dort jederzeit die neueste Sammlung herunterladen, um Ihre Reports in SchILD-NRW 3 zu ergänzen und auf den aktuellen Stand zu bringen.
