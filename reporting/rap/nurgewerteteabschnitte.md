# NurGewerteteAbschnitte

## Beschreibung

```pascal
NurGewerteteAbschnitte( zeigen: boolen );
```

## Parameter

| Parameter      | Bedeutung   |
|----------------|-------------|
| `zeigen` | `true` oder `false` |

## Beispiel

```pascal
NurGewerteteAbschnitte( false );
```

Der Standardwert ist **true**: Es werden nur gewertete Abschnitte angezeigt. Behalten Sie diese Einstellung für Reports bei, die ausschließlich gewertete Abschnitte verwenden dürfen, etwa Abiturübersichten. Mit **false** können Sie auch nicht gewertete Abschnitte anzeigen lassen, zum Beispiel auf einem Stammblatt. Das Beispiel oben zeigt diesen Aufruf.
