# EditRichText

## Beschreibung

```pascal
function EditRichText(Const Default: String): String;
```

## Parameter

| Parameter | Bedeutung                                      |
|-----------|------------------------------------------------|
| `Default` | Zu bearbeitender Richtext, kann auch leer sein |

## Rückgabewert

Veränderter Richtext

## Beispiel

```pascal
RichText1.RichText:=EditRichText('Hier den Text eingeben!');
```
