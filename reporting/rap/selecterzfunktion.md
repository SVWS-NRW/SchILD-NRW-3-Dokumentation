# SelectErzFunktion

## Beschreibung

```pascal
function SelectErzFunktion: String;
```

Diese Funktion bietet alle im Feld „Funktion“ im Katalog „Erzieher-Funktionen“ gefundenen Einträge zur Auswahl an.

## Rückgabewert

Erzieherfunktion

## Beispiel

Siehe „Filtererzieherfunktion“
