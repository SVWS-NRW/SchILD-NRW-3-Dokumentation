# Zahlwort

## Beschreibung

```pascal
function Zahlwort(aZahl: String): String;
```

## Parameter

| Parameter | Bedeutung                       |
|-----------|---------------------------------|
| `aZahl`   | Zahl in numerischer Darstellung |

## Rückgabewert

Zahl in Textform

## Beispiel

```pascal
Label1.Caption:=Zahlwort('3,51');
```

Ergebnis: 'Drei-Komma-Fünf-Eins'
