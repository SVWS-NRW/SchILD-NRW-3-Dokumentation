# Auswahl

Im Bereich Auswahl legen Sie fest, mit welchen Schülerinnen und Schülern Sie weiterarbeiten möchten. Filter grenzen die Datenmenge anhand bestimmter Merkmale ein und unterstützen so die Vorbereitung von Auswertungen und Gruppenprozessen.

Die Artikel erklären das Menüband und die Möglichkeiten des Schülerfilters. Prüfen Sie die resultierende Auswahl, bevor Sie darauf eine gemeinsame Bearbeitung anwenden.
