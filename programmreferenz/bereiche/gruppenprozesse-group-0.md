# Allgemein

Die allgemeinen Gruppenprozesse ändern gemeinsame Angaben oder führen Berechnungen für eine ausgewählte Schülergruppe aus. Dazu gehören unter anderem Wiedervorlagen, Datumsangaben und weitere organisatorische Merkmale.

Prüfen Sie vor dem Start die Schülerauswahl und die Voraussetzungen des jeweiligen Prozesses. Die folgenden Anleitungen erläutern, welche Felder geändert werden.
