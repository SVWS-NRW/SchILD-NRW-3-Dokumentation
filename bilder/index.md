# Bilderkatalog

Suchen Sie nach einem Programmfenster, einer Funktion oder einem Artikel. Der Katalog berücksichtigt Dateinamen, ursprüngliche Bildunterschriften und Verwendungsstellen.

Öffnen Sie ein Bild zur Prüfung und übernehmen Sie anschließend den Markdown-Code. Passen Sie die Bildbeschreibung an die neue Verwendung an. Mehrfach verwendete Bilder besitzen einen gemeinsamen Dateipfad.

Die Dateien liegen lokal unter `public/bilder/`. Ein Pfad wie `/bilder/schueler/individualdaten-i-uebersicht.png` wird in Markdown ohne den Bestandteil `public` verwendet.
