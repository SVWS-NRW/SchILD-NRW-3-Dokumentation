# Text-, CSV- und Tabellendateien bearbeiten

Nutzen Sie Tabellenkalkulation oder Texteditor für Import-, Export- und Schnittstellendateien. Der Artikel nennt Einsatzmöglichkeiten für Bearbeitung und Auswertung.

Text- und CSV-Dateien aus Im- und Exporten können Sie mit einem Tabellenkalkulationsprogramm öffnen, zum Beispiel OpenOffice Calc oder Microsoft Excel. **CSV** bezeichnet eine Textdatei, in der die Spalten durch Trennzeichen getrennt sind. Wie Sie eine solche Datei öffnen, hängt vom verwendeten Programm ab.

Auch reine Texteditoren können bei der Arbeit mit den Textdateien nützlich sein. Das bei Windows mitgelieferte *Notepad* ist oft schon ausreichend, *Notepad++* bringt weitaus umfassendere Features mit.

Zur Auswertung der Daten lohnt sich ein Blick auf die Diagramm- und Statistikfunktionen der Tabellenkalkulationsprogramme. Auch ein Blick auf Pivot-Tables kann hier neue Möglichkeiten eröffnen.
