# Automatische Prüfprozesse manuell starten

Starten Sie die sonst beim Programmstart regelmäßig ausgeführten Prüfungen bei Bedarf manuell. Dabei werden unter anderem fehlende Lernabschnitte und Änderungen altersbezogener Merkmale geprüft.

[![Automatische Prozesse manuelle anstoßen.](/bilder/schueler/einstellungen-automatische-prozesse-1.png)](/bilder/schueler/einstellungen-automatische-prozesse-1.png)

*Automatische Prozesse manuelle anstoßen.*

Diese Prozesse werden einmal pro Woche von SchILD-NRW beim Start automatisch angestoßen.

Sie können diese aber auch manuell mit diesem Menüpunkt ablaufen lassen. Diese ist über *Verwaltung ➜ Werkzeuge ➜ Automatische Prozesse ausführen* zu erreichen. Der Prozess wird mit **Automatische Prozesse starten** gestartet.

Prüfungen, die durchgeführt werden, sind zum Beispiel:

- Ob alle Schüler einen Lernabschnitt im aktuellen Halbjahr haben. Sollte z.B. bei einigen Schülern, die aus dem Karteikasten "Neuaufnahme" aktiviert wurden, noch nie der Reiter "Akt. Halbjahr" angeklickt worden sein, so wird dies an dieser Stelle nachgeholt.
- Sind Schülerinnen oder Schüler seit der letzten Prüfung volljährig geworden?
- An weiterführenden Schulen - außer an BKs - wird das Erreichen des Endes der Schulpflicht geprüft.

::: danger Achtung

Ein falsches Systemdatum von Windows kann zu unerwünschten Ergebnissen führen!

:::
