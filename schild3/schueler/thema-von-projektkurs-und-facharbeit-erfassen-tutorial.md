# Projektkurse, Facharbeiten und ihre Themen erfassen

**Geltungsbereich:** Das Beispiel zeigt einen Projektkurs in beiden Halbjahren der **Q1** nach der bisherigen APO-GOSt. [§ 11 Absatz 8](https://bass.schule.nrw/9607.htm) sieht zwei aufeinanderfolgende Halbjahre der Qualifikationsphase vor; der Kurs ist nicht generell auf Q1 beschränkt. Die neue Ordnung für die Kohorte ab EF 2027/28 ist getrennt zu behandeln; siehe [Prüfungsordnungen zuordnen](/zeugnisse/pruefungsordnungen).

Bereiten Sie Fach und Kurs vor und aktivieren Sie das fachbezogene Bemerkungsfeld. Anschließend können Sie Themen und Noten von Projektkurs- oder Facharbeiten dokumentieren.

## Fachbezogene Bemerkungen aktivieren

[![Aktivieren Sie die Fachbezogenen Bemerkungen.](/bilder/schueler/tutorials-projektkurse-einstellungen-fachbezogene-bemerkungen.png)](/bilder/schueler/tutorials-projektkurse-einstellungen-fachbezogene-bemerkungen.png)

*Aktivieren Sie die Fachbezogenen Bemerkungen.*

Damit das Thema der Projektkursarbeit in den Leistungsdaten in einem Kurs erfasst werden kann, muss in SchILD-NRW die Spalte mit den *Fachbezogenen Bemerkungen* angezeigt werden.

Dieses lässt sich über *Verwaltung ➜ Einstellungen ➜ Globale Einstellungen* mit einem Haken bei **Fachbezogenes Bemerkungsfeld zeigen** aktivieren.  

## Projektkurse vorbereiten

### Ein Unterrichtsfach anlegen

[![Legen Sie ein Fach an, das den Projektkursen zugeordnet werden kann.](/bilder/schueler/tutorials-projektkurse-fach.png)](/bilder/schueler/tutorials-projektkurse-fach.png)

*Legen Sie ein Fach an, das den Projektkursen zugeordnet werden kann.*

Für einen Projektkurs muss ein übergeordnetes *Fach* unter *Kataloge ➜ Unterrichtsfächer* angelegt werden.

Beginnen Sie das **Interne Kürzel** beispielsweise mit **PX** für Projektkurs. Ein Projektkurs in Biologie kann **PXB** heißen. Für einen Projektkurs mit den beiden Leitfächern Biologie und Chemie bietet sich **PXBC** an.

Setzen Sie als **ASD-Kürzel** den Eintrag *PX*.

Vergeben Sie die Bezeichnung wie üblich und befüllen Sie die anderen Felder ebenso nach den Vorgaben beziehungsweise die frei wählbaren Felder wie gewünscht.

Als **Bereich auf dem Zeugnis** ist *Projektkurs* zu wählen. Ordnen Sie das **Aufgabenfeld** passend zu.

Unter **Sonstige Einstellungen** sind die Haken bei **Fach der Oberstufe** und **Bei "abgeschlossene Fächer holen" berücksichtigen** anzuwählen, wenn der Projektkurs wie im Beispiel vor dem Abschlussabschnitt endet.

Achten Sie auch daran, dass das Fach bei *auf Zeugnis* und *Sichtbar* angehakt ist.  

### Den Kurs anlegen

[![Konfigureren Sie den Projektkurs für beide Halbjahre der Q1.](/bilder/schueler/tutorials-projektkurse-kurs.png)](/bilder/schueler/tutorials-projektkurse-kurs.png)

*Konfigureren Sie den Projektkurs für beide Halbjahre der Q1.*

Der Kurs ist über *Kataloge ➜ Kurse* anzulegen.

Klicken Sie auf das **+**.  
Achten Sie darauf, den Kurs für das richtige Halbjahr anzulegen (Q1, 1. beziehungsweise 2. Halbjahr).

Die Kursbezeichnung ist frei zu vergeben, hier wird *BI-PX1* gewählt. Legen Sie einen Projektkurs mit zwei Leitfächern an, könnte der Kurs *BiC-PX* oder *BC-PX1* genannt werden.

Als **Fach** ist das eben angelegte Fach zu wählen, hier im Beispiel *PXB*. Als **alg. Kursart** wird *PJK* gewählt. Wie Projektkurse aktuell anzulegen sind, ist den Schlüsseltabellen für die Statistik zu entnehmen, die an Ihrer Schule hierfür verantwortlich Person kann im Zweifelsfall helfen.

Tragen Sie die gewünschte **Zeugnisbezeichnung** ein.

Legen Sie die übrigen Daten entsprechend der anderen Oberstufenkurse an. Achten Sie auf die **Schienen**.

Wählen Sie die bei Ihnen für Kurse der Oberstufe verwendete **Kursart**. Legen Sie den Kurs in den tatsächlich vorgesehenen Halbjahren an; im Beispiel sind dies Q1.1 und Q1.2.

Bei Bedarf: Sie können den Kurs ganz links markieren, mit der rechten Maustaste ein Kontextmenü aufrufen, um den Kurs zu kopieren. Nun kann er in einem anderen Halbjahr, üblicherweise Q1, 2. Halbjahr, eingefügt werden.  

::: tip Richtig – Fertig

**Starten Sie SchILD-NRW neu**, damit die Kataloge und damit die Kurse einmal komplett neu eingelesen werden.

Der Kurs kann im Anschluss bei Schülern in die Leistungsdaten aufgenommen werden.

:::

## Den Projektkurs verwenden

### Kurs bei Schüler hinzufügen

[![Fügen Sie den Kurs wie gewohnt unter Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten dem Schüler zu.](/bilder/schueler/tutorials-projektkurse-schueler-kurs.png)](/bilder/schueler/tutorials-projektkurse-schueler-kurs.png)

*Fügen Sie den Kurs wie gewohnt unter Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten dem Schüler zu.*

Der Kurs wird individuell wie gewohnt unter *Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten* aufgenommen.

Verfahren Sie bei Gruppen oder dem Halbjahreswechsel wie mit anderen Kursen auch, zum Beispiel durch Zuordnen per Gruppenprozesse, über die Fortschreibungsart beim Abschnittswechsel oder durch einen Import aus einem externen Blockungs- und Kursplanungsprogramm.

Achten Sie darauf, den Kurs in beiden Halbjahren der Q1 zuzuordnen.  

### Thema der Projektkursarbeit erfassen

[![Tragen Sie das Theme das Projektkurses unter der Fachbez. Leistungsentw. ein.](/bilder/schueler/tutorials-projektkurse-schueler-thema.png)](/bilder/schueler/tutorials-projektkurse-schueler-thema.png)

*Tragen Sie das Theme das Projektkurses unter der **Fachbez. Leistungsentw.** ein.*

Das Projektkursthema wird unter **Fachbez. Leistungsentw.** erfasst. Führen Sie einen `Doppelklick` auf das Feld aus.

Im folgenden Fenster wird das Thema eingetragen.

Bestätigen Sie mit einem Klick auf `OK`.

Es reicht, das Thema in einem Halbjahr eintragen.  

::: tip Tipp

Da die Arbeit im zweiten Halbjahr geschrieben wird, bietet es sich an, per Konvention die Arbeiten immer im 2. Halbjahr der Q1 zu erfassen.

:::

### Im Abitur

[![Übernehmen Sie das Thema in Schüler ➜ Abitur.](/bilder/sekundarstufen/tutorials-projektkurse-schueler-abitur.png)](/bilder/sekundarstufen/tutorials-projektkurse-schueler-abitur.png)

*Übernehmen Sie das Thema in Schüler ➜ Abitur.*

Im Zuge des Abiturs können Sie das Thema der Projektkursarbeit unter **Projektkurs** frei eintragen.

Wurde das Thema als *Fachbezogene Leistungsentwicklung* unter *Schüler Akt. Halbjahr Leistungsdaten* in der Q1 beim Kurs erfasst, klicken Sie auf `Thema ermitteln` um es einzulesen.  

::: tip Richtig – Fertig

Der Projektkurs wird nun auf dem Abiturzeugnis mit Kursthema und Projektkursarbeit ausgegeben.

:::

### Note der Projektkursarbeit oder einer Facharbeit erfassen

Noten von Projektkursarbeiten und Facharbeiten lassen sich als *Teilleistung* bei den Daten des Faches erfassen.

Legen Sie zuerst eine Teilleistung *Projektursarbeit* und/oder *Facharbeit* über *Kataloge ➜ Teilleistungsarten* an.

Dann können Sie Teilleistungen über *Gruppenprozesse ➜ Teilleistungen* ➜ **Teilleistungsarten individuell zuweisen** die Teilleistungen *Projektkursarbeit* oder *Facharbeit* der ausgewählten Schülermenge zuweisen.

Wählen Sie passend *Fach*, *Kursart* und die *Teilleistung*.

Klicken Sie dann auf `Ausführen`.

Im Anschluss kann die Teilleistung über *Schüler Akt. Halbjahr Leistungsdaten* beim zugeordneten Fach mit der Note in einem Lernabschnitt hinzugefügt werden.

::: info Hinweis

Konsultieren Sie bei Bedarf die ausführlicheren Artikel zu *Teilleistungen* in dieser Dokumentation.

:::
