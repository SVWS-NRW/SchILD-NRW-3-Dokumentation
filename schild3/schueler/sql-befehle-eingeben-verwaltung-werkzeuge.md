# SQL-Befehle über die Verwaltungswerkzeuge ausführen

Öffnen Sie als Administration die SQL-Eingabe für besondere Prüf- oder Korrekturaufgaben. Beachten Sie die im Artikel beschriebenen Grenzen und die Rücksprache mit der Fachberatung.

[![SQL-Befehle eingeben - hier ein harmloses Beispiel...](/bilder/schueler/werkzeuge-sql-1.png)](/bilder/schueler/werkzeuge-sql-1.png)

*SQL-Befehle eingeben - hier ein harmloses Beispiel...*

[![... mit einem harmlosen Ergebnis.](/bilder/schueler/werkzeuge-sql-2-ergebnis.png)](/bilder/schueler/werkzeuge-sql-2-ergebnis.png)

*... mit einem harmlosen Ergebnis.*

Sie haben als *Administrator* die Möglichkeit, beliebige SQL-Befehle in der Datenbank auszuführen.

Diese Funktion ist über *Verwaltung ➜ Werkzeuge ➜ SQL-Befehle eingeben* zu erreichen.

::: tip Tipp

Reines Nachschauen, wie bestimmte Werte erfasst werden, kann mitunter bei einer bestimmten Aufgabe hilfreich sein.

:::

Überlegen Sie bitte sehr genau, ob eine *Veränderung*, zum Beispiel das Anlegen einer neuen Tabelle oder ein direktes Umsetzen bestimmter Werte, auch tatsächlich sinnvoll ist.

In außergewöhnlichen Situationen kann es eventuell notwendig sein, bestimmte Daten direkt zu ändern. Dies ist über dieses Werkzeug möglich.

Halten Sie bitte Rücksprache mit Ihrer Fachberatung!  

::: danger Achtung

Für eigenmächtig veränderte Datenbanken können u.U. keine Garantie oder Support mehr übernommen werden!

:::
