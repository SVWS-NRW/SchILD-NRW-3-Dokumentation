# Den Online-Support mit der Fachberatung starten

Starten Sie in Absprache mit der Fachberatung das mitgelieferte Supportprogramm, um den Desktop für die gemeinsame Fehlersuche freizugeben.

::: info Hinweis

Eventuell nutzen die Fachberatungen der Bezirksregierungen ein von dem mitgelieferten abweichendes Tool. In diesem Fall wäre das Vorgehen direkt im Telefonat/Videochat mit der Fachberatung zu klären.

:::

[![Starten Sie über Verwaltung das Online-Supportprogramm.](/bilder/schueler/verwaltung-online-supportprogramm.png)](/bilder/schueler/verwaltung-online-supportprogramm.png)

*Starten Sie über Verwaltung das **Online-Supportprogramm**.*

Bei der Fehlersuche kann die Fachberatung Sie bitten, Ihren Desktop über das Supportprogramm freizugeben. Stimmen Sie das Vorgehen im Telefonat oder in der Videokonferenz ab.

Hierzu liefert SchILD-NRW das Programm *Teamviewer* mit. Dieses liegt in SchILD-NRW-Installationsverzeichnis im Ordner *OnlineSupport*.

Das Programm kann über *Verwaltung* mit einem Klick auf `Online-Supportprogramm starten` direkt aus SchILD-NRW aufgerufen werden.  

[![Im Supportprogramm werden die für die Fachberatung benötigten Daten zur Verbindung angezeigt.](/bilder/schueler/verwaltung-online-supportprogramm-tw.png)](/bilder/schueler/verwaltung-online-supportprogramm-tw.png)

*Im Supportprogramm werden die für die Fachberatung benötigten Daten zur Verbindung angezeigt.*

Es öffnet sich ein Fenster, in dem eine **ID** und ein **Passwort** angezeigt werden. Diese Daten müssen der Fachberatung mitgeteilt werden, dann wird Ihr Desktop mit dem Gegenüber geteilt.

Auch eine Fernsteuerung Ihres Geräts wird über TeamViewer ermöglicht.

::: info Hinweis

Achten Sie bitte darauf, nicht auf eventuelle Phishingangriffe hereinzufallen, d.h. dass sich jemand Fremdes als berechtigte Person ausgibt. Teilen Sie diese Daten nur mit vertrauenswürdigen Gesprächspartnern im Kontext einer Beratungssituation.

:::

Über das Zahnrad oben rechts lassen sich auch Konfigurationseinstellungen für Audio und Video vornehmen, so dass der TeamViewer zusätzlich als Werkzeug für eine Videokonferenz dient.
