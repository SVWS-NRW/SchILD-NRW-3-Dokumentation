# Die Versionsgeschichte öffnen

Öffnen Sie die Versionshinweise, um Änderungen und Fehlerkorrekturen einzelner Programmfassungen nachzuschlagen.

[![Ein Klick auf Verwaltung ➜ Hilfe ➜ Versionsgeschichte zeigen öffnet den Link auf die Seite mit der Versionsgeschichte von SchILD-NRW 3.](/bilder/schueler/verwaltung-hilfe-versionsgeschichte.png)](/bilder/schueler/verwaltung-hilfe-versionsgeschichte.png)

*Ein Klick auf Verwaltung ➜ Hilfe ➜ **Versionsgeschichte zeigen** öffnet den Link auf die Seite mit der Versionsgeschichte von SchILD-NRW 3.*

Ein Klick auf *Verwaltung ➜ Hilfe* ➜ **Versionsgeschichte zeigen** öffnet den Link auf die Seite mit der Versionsgeschichte von SchILD-NRW.

Hier können Anmerkungen zu Features und Fixes zu neuen und vergangenen Versionen nachgelesen werden.

Die [Seite zur Versionsgeschichte](/schild3/schueler/versionsgeschichte-von-schild-nrw-3) befindet sich in dieser Dokumentation.
