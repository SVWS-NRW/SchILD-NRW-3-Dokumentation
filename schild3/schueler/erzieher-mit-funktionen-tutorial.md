# Erziehungsberechtigte über Personengruppen zuordnen

Bilden Sie Funktionen von Erziehungsberechtigten über zuvor angelegte Personengruppen ab und ordnen Sie die betreffenden Personen zu.

::: danger Achtung

*Erzieherfunktionen'* werden in SchILD-NRW 3 über Personengruppen erfasst.

:::

## Personengruppen vorbereiten und zuordnen

Erstellen Sie für Erzieherfunktionen passende **Personengruppen** über ***Kataloge ➜ Personengruppen***. Beachten Sie **[den Artikel zu den Personengruppen](/schild3/unterricht-kataloge/personengruppen-schulbezogene-kataloge)** für weitere Informationen.

Sie können anschließend auf dem Reiter der Erzieher einen Klick mit der **rechten** Maustaste auf die Anrede, den Namen oder den Titel eines Erziehers ausführen. Im Kontextmenü können Sie diesen Erzieher dann einer vorab definierten Personengruppe zuordnen.
