# Die schulische Herkunft an BK und WBK erfassen

Tragen Sie die zuvor besuchte Schule und die Herkunftsangaben ein. Unterscheiden Sie Schulen in NRW, Schulen außerhalb von NRW und eine unbekannte Herkunft.

[![Tragen Sie die Herkunft von Schülern unter Schüler ➜ Schulbesuch ein.](/bilder/schueler/tutorials-bk-herkunft-eintragen.png)](/bilder/schueler/tutorials-bk-herkunft-eintragen.png)

*Tragen Sie die Herkunft von Schülern unter Schüler ➜ Schulbesuch ein.*

## Herkunft unter Schulbesuch eintragen

Tragen Sie die Herkunft der Schüler mit den bekannten Daten unter *Schüler* ➜ **Schulbesuch** ein.

## Schulen aus NRW

Wenn Sie eine Schule eintragen, wird die Schulnummer automatisch ausgefüllt.

Befindet sich eine Schule nicht im Dropdown-Menü zur Auswahl, lässt sich über das **+** neben dem Dropdown-Menü der Katalog mit den Schulnummern von Schulen in NRW öffnen.

Sie gelangen auf den Katalog, der auch über *Kataloge ➜ Schulen in NRW* zu erreichen ist. Diese Schulen stehen im Dropdown-Menü in Ihrem SchILD zur Verfügung.

Klicken Sie auch in diesem Katalog auf **+**. Suchen Sie die fehlende Schule über die Bezeichnung oder Schulnummer und fügen Sie sie dem Katalog hinzu. Anschließend können Sie die Schule unter **Schulbesuch** auswählen.

Wählen Sie die Schule in **Schulbesuch** an und tragen Sie die Daten ein.

Fügen Sie dann die Schule mit einem Klick auf den Rechtspfeil (➜) der Liste *Alle bisher besuchten Schulen* ein.  

## Schulen außerhalb von NRW

[![Schüler, die eine Herkunft außerhalb von NRW haben, werden über Sammel-Schulnummern erfasst.](/bilder/schueler/tutorials-bk-herkunft-andere-schule.png)](/bilder/schueler/tutorials-bk-herkunft-andere-schule.png)

*Schüler, die eine Herkunft außerhalb von NRW haben, werden über Sammel-Schulnummern erfasst.*

Kommt ein Schüler aus einer Schule die nicht in NRW liegt, öffnen Sie *Kataloge ➜ Andere Schulen und Schulnummern* und fügen Sie einen passenden Eintrag in Ihre Kataloglist.

Zur Auswahl stehen hier die Bundesländer, *Schule aus den Niederlanden*, *Schule aus dem sonstigen Ausland* und *Sonstige/keine Schule*.

## Unbekannte Herkunft

Die letzte Schulnummer kann auch für *unbekannte Herkunft* verwendet werden. Füllen Sie hierbei alle bekannten Daten aus und lassen Sie die Felder mit unbekannten Daten frei.

::: tip Tipp

Da es sich nicht um viele Schulen/Schulnummern handelt, fügen Sie einmal alle dem Katalog hinzu. Dann stehen diese im Bedarfsfall direkt zur Verfügung.

:::

::: info Hinweis

Wenn Sie die Schule *Sonstige/keine Schule* eintragen, lässt sich die Schule natürlich auch nicht mit dem Pfeil in die *bisher besuchten Schulen* verschieben.

:::
