# Alte Schuljahresdaten aufräumen

Entfernen Sie nicht mehr benötigte Daten abgeschlossener Schuljahre mit dem Werkzeug Aufräumen. Die Löschung ist unwiderruflich; prüfen Sie Umfang und Datensicherung vor dem Start.

::: danger Achtung

**Vor dieser Aktion sollte unbedingt eine Datensicherung erfolgen.**

Nach der Löschung können keine Leistungsdaten der Lernabschnitte mehr abgerufen werden.

Entscheiden Sie vor dem Aufräumen, welche Schuljahre Sie bearbeiten möchten und welche Daten daraus gelöscht werden dürfen.

:::

[![Löschen von Daten in Lernabschnitten per Aufräumen.](/bilder/schueler/verwaltung-werkzeuge-aufraeumen.png)](/bilder/schueler/verwaltung-werkzeuge-aufraeumen.png)

*Löschen von Daten in Lernabschnitten per Aufräumen.*

Öffnen Sie **Verwaltung → Werkzeuge → Aufräumen**. Wählen Sie im Dialog das **Schuljahr, in dem aufgeräumt werden soll**.

Nach Anklicken des Schalters "**Jetzt aufräumen**" gibt es eine Warnmeldung:

*"Es werden sämtliche Daten von Schülern mit Status „Abgänger“, „Abschluss“ oder „Gelöscht“ im Schuljahr … gelöscht … Wollen Sie das wirklich tun?".*

Bei **Ja** werden diese Daten unwiderruflich (ohne Log-Dateien) aus der Datenbank entfernt.

Somit entfallen auch die Verknüpfungen der Lehrkräfte mit Klassen und Unterricht für den ausgewählten Zeitraum, so dass dann auch die ausgeschiedenen Lehrkräfte für diese Schuljahre gelöscht werden können.  

::: info Hinweis

Prüfen Sie Aufbewahrungsfristen und Archivierung vor dieser umfangreichen Löschung. Das Ausblenden einer ausgeschiedenen Lehrkraft verändert nur die Anzeige und ersetzt keine erforderliche Löschung. Verwenden Sie für die fristbezogene Prüfung den unten genannten Löschfristen-Dialog.

:::

::: tip Tipp

Nutzen Sie zur Datenpflege bitte die am Rechtsrahmen ausgerichtete automatische *Prüfungen von Löschfristen*, die Sie bei der Wahrung des Datenschutzes unterstützt.

:::
