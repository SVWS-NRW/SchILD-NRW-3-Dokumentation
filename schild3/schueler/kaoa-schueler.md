# KAoA-Module erfassen und archivieren

Dokumentieren Sie absolvierte Module der beruflichen Orientierung. Die verfügbaren Module richten sich nach dem Jahrgang; der KAoA-Reiter muss bei Bedarf erst eingeblendet werden.

In diesem Reiter können für den ausgewählten Schüler Module der beruflichen Orientierung von *"Kein Abschluss ohne Anschluss - Übergang Schule-Beruf NRW"*, KAoA, verwaltet und archiviert werden.

Die Module sind einheitlich vorgegeben und sind in SchILD-NRW bereits hinterlegt. Die zur Verfügung stehenden Module richten sich nach dem jeweils ausgewählten Jahrgang.

::: info Hinweis

Maßnahmen der beruflichen Orientierung im Rahmen von KAoA beginnen an den weiterführenden Schulen mit dem Jahrgang 8.

:::

## Anzeigen des KAoA-Reiters

[![Anzeigen des KAoA-Reiters unter Verwaltung ➜ Einstellungen ➜ Globale Einstellungen: Allgemeines ➜ Ansicht.](/bilder/schueler/k-ao-a-einstellungen-reiter-aktivieren.png)](/bilder/schueler/k-ao-a-einstellungen-reiter-aktivieren.png)

*Anzeigen des KAoA-Reiters unter Verwaltung ➜ Einstellungen ➜ Globale Einstellungen: Allgemeines ➜ Ansicht.*

Blenden Sie den Reiter **KAoA** zunächst über die globalen Einstellungen ein.

Der Reiter kann über *Verwaltung ➜ Einstellungen ➜ Globale Einstellungen* und dann in *Allgemeines ➜ Ansicht* ➜ **Karteireiter 'KAoA" zeigen** per Haken aktiviert und deaktiviert werden.  

## Anlegen von absolvierten Modulen

[![Anlegen von absolvierten Modulen unter Schüler ➜ KAoA.](/bilder/schueler/k-ao-a-massnahme-anlegen.png)](/bilder/schueler/k-ao-a-massnahme-anlegen.png)

*Anlegen von absolvierten Modulen unter Schüler ➜ KAoA.*

Im entsprechenden Reiter können für ausgewählten Schüler absolvierte Module angelegt und so archiviert werden.  

[![Das Auswahlfenster zur Auswahl der absolvierten Module.](/bilder/schueler/k-ao-a-03.png)](/bilder/schueler/k-ao-a-03.png)

*Das Auswahlfenster zur Auswahl der absolvierten Module.*

Klicken Sie auf **+**. Im Auswahlfenster wählen Sie nacheinander **Kategorie**, **Merkmal** und **Zusatzmerkmal** für den Jahrgang aus.

Die auswählbaren weiteren Merkmale hängen vom jeweils vorherigen ab, so dass nur zulässige Kombinationen eingeben werden können.

Ein Klick auf das "**-**" löscht ein fälschlich zugeordnetes Merkmal.  

## Gruppenprozesse

[![Anlegen von absolvierten Modulen per Gruppenprozess unter Gruppenprozesse: Allgemein ➜ KAoA.](/bilder/schueler/k-ao-a-04.png)](/bilder/schueler/k-ao-a-04.png)

*Anlegen von absolvierten Modulen per Gruppenprozess unter Gruppenprozesse: Allgemein ➜ KAoA.*

Da häufig Klassen oder Jahrgangsstufen zusammen die Module von KAoA absolvieren, bietet es sich an, die Merkmale wie im Beispiel dargestellt per Gruppenprozess zuzuweisen.
