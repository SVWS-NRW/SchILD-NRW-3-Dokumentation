# Bemerkungen zum Lernabschnitt erfassen

Erfassen Sie Zeugnisbemerkungen, Angaben zum Arbeits- und Sozialverhalten und zum außerunterrichtlichen Engagement. Nutzen Sie bei Bedarf die hinterlegten Floskeln und Variablen.

[![Übersicht der Bemerkungen zu einem Lernabschnitt.](/bilder/schueler/akt-halbj-bemerkungen-1.png)](/bilder/schueler/akt-halbj-bemerkungen-1.png)

*Übersicht der Bemerkungen zu einem Lernabschnitt.*

Zu jedem Lernabschnitt können *Bemerkungen* erfasst werden. Diese können über Reports ausgegeben werden, zum Beispiel auf Zeugnissen.

Es können Bemerkungen zu unterschiedlichen Kategorien erfasst werden, wie dem **Arbeits- und Sozialverhalten**, den **Zeugnisbemerkungen und dem Außerunterrichtlichen Engagement**. Eine **Bemerkung zum Förderschwerpunkt** kann nur eingetragen werden, wenn beim Schüler im aktuellen Halbjahr ein Förderschwerpunkt hinterlegt wurde. 

[![Der Floskeleditor für Bemerkungen.](/bilder/schueler/akt-halbj-bemerkungen-2.png)](/bilder/schueler/akt-halbj-bemerkungen-2.png)

*Der Floskeleditor für Bemerkungen.*

Doppelklicken Sie in das gewünschte Bemerkungsfeld. Im folgenden Fenster können Sie den vorhandenen Text bearbeiten.

Sie können den Text direkt eingeben oder vorbereitete **Floskeln**, also wiederverwendbare Textbausteine, mit einem Doppelklick einfügen.

Im Floskeleditor kann über das Dropdown-Menü zum Filtern eingestellt werden, welche *Floskelgruppe* angezeigt wird. Per Standard ist der Filter auf das Feld eingestellt, über welches der Floskeleditor geöffnet wurde.

Floskeln können **Variablen** enthalten, die beim Einfügen durch Daten der ausgewählten Person ersetzt werden. Zum Beispiel steht `$Vorname$` anschließend für deren Vornamen.

Mit einem Haken bei **Mehrfache Nennung des Vornamens vermeiden** wird bei weiteren direkt im Anschluss eingefügten Floskeln der Vorname durch "er" oder "sie" ersetzt.

::: info Hinweis

Neue Floskeln können über *"Kataloge"* ➜ *"Floskeln bearbeiten"* zentral angelegt und dann hier genutzt werden.

:::

[![Beispielergebnisse einer Bearbeitung.](/bilder/schueler/akt-halbj-bemerkungen-3.png)](/bilder/schueler/akt-halbj-bemerkungen-3.png)

*Beispielergebnisse einer Bearbeitung.*

Unter den Bemerkungen wird hier auch der Bereich für die *Zeugnis- und Abschlussdaten* des aktuellen Abschnitts eingeblendet.
