# Stundentafeln für Jahrgänge und Klassen vorbereiten

Fassen Sie Unterrichtsfächer zu Stundentafeln zusammen, die später einer Schülergruppe zugewiesen werden können. Legen Sie Geltungsbereich und die einzelnen Fächer fest.

[![Über Kataloge ➜ Stundentafel können Fachzuordnungen als Vorlage definiert werden.](/bilder/unterricht-kataloge/kataloge-stundentafeln.jpg)](/bilder/unterricht-kataloge/kataloge-stundentafeln.jpg)

*Über Kataloge ➜ Stundentafel können Fachzuordnungen als Vorlage definiert werden.*

Die Stundentafeln werden genutzt, um ganzen Klassen, Jahrgängen oder Schülergruppen auf einmal einen bestimmten Satz von Unterrichtsfächern zuzuordnen.

Typischerweise ist dies der Klassenunterricht. Diese Fächerzuordnung findet ohne Kursbezeichnung nur mit einer bestimmten Kursart statt: PUK - Pflichtunterricht für die (gesamte) Klasse.

Legen Sie im oberen Teil des Dialogs mit **+** eine neue Stundentafel an.

Geben Sie dieser einen **Jahrgang**, für den die Stundentafel gelten soll. Bleibt das Jahrgangsfeld leer, gilt ist die Stundentafel jahrgangsübergreifend.

In der Schulform *Berufskolleg* kann für die Stundentafel noch die Fachklasse gewählt werden, für die die Stundentafel gelten soll.  

[![Legen Sie die Fächer an, die später den Schülern einer bestimmten Gruppe hinzugefügt werden sollen. Hier im Beispiel wird eine Stundentafeln für alle Klassen des Jahrgangs 5 definiert.](/bilder/unterricht-kataloge/kataloge-stundentafeln-faecher-anlegen.jpg)](/bilder/unterricht-kataloge/kataloge-stundentafeln-faecher-anlegen.jpg)

*Legen Sie die Fächer an, die später den Schülern einer bestimmten Gruppe hinzugefügt werden sollen. Hier im Beispiel wird eine Stundentafeln für alle Klassen des Jahrgangs 5 definiert.*

Ist die Stundentafel angelegt, können im unteren Bereich des Fensters die einzelnen Fächer hinzugefügt werden.

Die Fächer können mit **Kursart** und **Wochenstundenzahl** angelegt werden.

Im Beispiel finden sich bei **WZE** so hohe Zahlen, da die Schule die WZE in *Minuten* erfasst. Üblicherweise werden hier 45-Miunuten-Blöcke eingetragen.

Variiert die Wochenstundenzahl innerhalb eines Jahrgangs, können Sie das Feld leer lassen oder einen Standardwert eintragen. Diesen Wert können Sie später anpassen.

Das Anlegen von Stundentafeln kann als Vorbereitung zur Zuweisung von Klassenunterricht gesehen werden.

::: info Hinweis

Die Einrichtung der Stundentafeln legt noch keine Datensätze in den Leistungsdaten der Schüler an. Diese Zuordnung wird später über Gruppenprozesse vorgenommen.

:::

::: tip Tipp

Erst mit dem Gruppenprozess Stundentafeln zuweisen werden diese bei den Schülern aktiviert. In aller Regel werden dann die fehlenden Angaben zum unterrichtenden Lehrer über den Gruppenprozess Klassenunterrichte bearbeiten vervollständigt.

:::
