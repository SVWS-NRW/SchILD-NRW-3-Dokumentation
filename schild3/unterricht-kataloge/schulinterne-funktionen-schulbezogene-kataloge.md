# Schulinterne Funktionen für Lehrkräfte vorbereiten

Definieren Sie die schulischen Funktionen im Katalog, bevor Sie diese Lehrkräften in den zeitabhängigen Daten zuweisen.

Unter **Kataloge ➜ Schulinterne Funktionen** legen Sie fest, welche dieser Funktionen Sie für Ihre Lehrkräfte an Ihrer Schule vergeben möchten.

Wurde eine schulinterne Funktion definiert, kann diese im Bereich **Lehrkräfte ➜ Zeitabhängige Daten** und dann im Reiter **Schulinterne Funktionen** mit einem Klick auf das **Plus +** zugewiesen werden.

Die Liste der Funktionen wird im Katalogbereich bearbeitet. Die individuelle Zuordnung erfolgt weiterhin bei den zeitabhängigen Lehrkräftedaten.
