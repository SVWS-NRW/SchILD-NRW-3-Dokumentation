# Bezeichnungen für telefonische Kontakte vorbereiten

Legen Sie die Bezeichnungen der telefonischen Ansprechpartner fest. Diese stehen anschließend bei den weiteren Telefonnummern der Schülerdatensätze zur Verfügung.

[![Karteireiter Kataloge ➜ Telef. Ansprechpartner.](/bilder/unterricht-kataloge/kataloge-telef-ansprechpartner.png)](/bilder/unterricht-kataloge/kataloge-telef-ansprechpartner.png)

*Karteireiter Kataloge ➜ Telef. Ansprechpartner.*

In diesem Katalog legen Sie **Bezeichnungen für Ansprechpartner** an, etwa „Mutter“ oder „Wohngruppe“. Die konkreten Telefonnummern erfassen Sie anschließend beim Schülerdatensatz.

Hier stellen sie alle weiteren Telefonkontakte bereit, die Sie verwenden bzw. eintragen wollen.

In der Regel finden sich hier Einträge wie Vater, Mutter, Großeltern, Wohngruppe etc.

::: tip Tipp

Die Bezeichnung soll zeigen, welche Person unter der Nummer erreichbar ist. **Mutter (Notfall)** ist zum Beispiel eindeutiger als **Notfallnummer**. Die Bezeichnung allein sagt nicht aus, ob eine Person erziehungsberechtigt ist; prüfen Sie diese Angabe getrennt.

:::

[![Karteireiter Schüler / Erziehungsberechtigte](/bilder/unterricht-kataloge/schueler-erz-berechtigte-telefonnummern.png)](/bilder/unterricht-kataloge/schueler-erz-berechtigte-telefonnummern.png)

*Karteireiter Schüler / Erziehungsberechtigte*

Auf dem Karteireiter *Schüler ➜ Erziehungsberechtigte* können nun weitere Telefonnummern mit den Ansprechpartnern aus dem Katalog eingetragen werden.
