# Teilleistungen eines Lernabschnitts löschen

Löschen Sie alle Teilleistungen der ausgewählten Schülergruppe für einen bestimmten Lernabschnitt. Das Auswahlfenster erlaubt auch die Wahl eines früheren Abschnitts.

[![Löschen aller Teilleistungen eines Abschnitts über Gruppenprozesse (Teilleistungen) ➜ Teilleistungen für einen Abschnitt löschen.](/bilder/suchen-gruppenprozesse/gruppenprozesse-teilleistungen-fuer-einen-abschnitt-loeschen-01.png)](/bilder/suchen-gruppenprozesse/gruppenprozesse-teilleistungen-fuer-einen-abschnitt-loeschen-01.png)

*Löschen aller Teilleistungen eines Abschnitts über Gruppenprozesse (Teilleistungen) ➜ Teilleistungen für einen Abschnitt löschen.*

Der Gruppenprozess **Teilleistungen für einen Abschnitt löschen** entfernt alle Teilleistungen der ausgewählten Schülergruppe im gewählten Lernabschnitt.

Ein Klick auf diesen Gruppenprozess öffnet das im Beispiel rechts gezeigte Auswahlfenster, in dem der entsprechende Abschnitt ausgewählt werden kann. Es können also auch für vergangene Abschnitte Teilleistungen gelöscht werden.

Nach Klick auf `OK` erfolgt eine Bestätigungsaufforderung.

Danach werden für den gewünschten Abschnitt für alle im Container ausgewählten Schüler alle Teilleistungen gelöscht.

::: danger Achtung

Berücksichtigen Sie, dass die Teilleistungen komplett aus den Leistungsdaten gelöscht werden.

:::
