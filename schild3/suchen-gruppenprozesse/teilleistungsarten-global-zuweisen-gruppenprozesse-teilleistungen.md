# Teilleistungsarten allen Fächern einer Gruppe zuweisen

Weisen Sie vorbereitete Teilleistungsarten allen Fächern der ausgewählten Schülerinnen und Schüler zu. Dieser Gruppenprozess unterscheidet nicht nach Fach oder Kursart.

[![Zuweisung von angelegten Teilleistungsarten über Gruppenprozesse ➜ Teilleistungen ➜ Teilleistungen global zuweisen.](/bilder/suchen-gruppenprozesse/gruppenprozesse-teilleistungsarten-global-zuweisen-01.png)](/bilder/suchen-gruppenprozesse/gruppenprozesse-teilleistungsarten-global-zuweisen-01.png)

*Zuweisung von angelegten Teilleistungsarten über Gruppenprozesse ➜ Teilleistungen ➜ **Teilleistungen global zuweisen**.*

Durch den Gruppenprozess **Teilleistungsarten global zuweisen** können der ausgewählten Schülergruppe beliebige Teilleistungsarten global zugewiesen werden, was bedeutet, dass jedem Fach aller ausgewählten Schüler im gewünschten Lernabschnitt diese Teilleistungsart zugewiesen wird.

::: example Beispiel

Über diese Funktion könnte zum Beispiel in der Oberstufe eine explizite "Mündliche Note" und "Schriftliche Note" erhoben werden oder für alle Jahrgänge eine Note für den "Elternsprechtag" eingeholt werden.

:::

Wie im Beispiel rechts dargestellt können der aktuell ausgewählten Schülermenge im Container jegliche im *Katalog ➜ Teilleistungsarten* vorbereitete Teilleistungsarten zugeordnet werden.

Bei Ausführung des Gruppenprozesses wird die ausgewählte Teilleistungsart jedem Fach der im Container ausgewählten Schüler hinzugefügt.

Im Beispiel hier wird also die Teilleistungsart "KA 3" (für "Klassenarbeit 3") auch bei mündlichen Fächern mit angelegt. Eine hinzugefügte Teilleistung muss nicht ausgefüllt werden.

::: info Hinweis

Berücksichtigen Sie, dass bei diesem Gruppenprozess nicht nach Fächern oder Kursarten unterschieden wird, es wird jedem Fach in den Leistungsdaten der Schüler die entsprechende Teilleistungsart zugewiesen. Die Teilleistungen lassen sich global nicht so einfach wieder entfernen.

:::
