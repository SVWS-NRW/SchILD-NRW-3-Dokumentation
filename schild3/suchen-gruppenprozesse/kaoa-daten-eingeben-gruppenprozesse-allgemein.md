# KAoA-Maßnahmen gruppenweise erfassen

Tragen Sie eine Maßnahme der beruflichen Orientierung für die ausgewählte Schülergruppe ein. Die benötigten Zusatzangaben hängen vom gewählten Merkmal ab.

[![Geben Sie die KAoA-Daten ein. Der Prozess wird mit Ausführen gestartet. Hier im Beispiel würde der Gruppenprozess auf den fehlenden Freitext hinweisen.](/bilder/suchen-gruppenprozesse/gruppenprozesse-k-ao-a.png)](/bilder/suchen-gruppenprozesse/gruppenprozesse-k-ao-a.png)

*Geben Sie die KAoA-Daten ein. Der Prozess wird mit `Ausführen` gestartet. Hier im Beispiel würde der Gruppenprozess auf den fehlenden Freitext hinweisen.*

Wurde im Container auf eine Schülergruppe gefiltert, für die KAoA-Daten eingegeben werden sollen, erscheint unter *Gruppenprozesse Allgemein* der Prozess **KAoA-Daten eingeben**.

Tragen Sie die Angaben zur durchgeführten Maßnahme entsprechend den Vorgaben ein.

Welche **Zusatzmerkmale** zur Auswahl stehen, hängt vom gewählten **Merkmal** ab.

Klicken Sie anschließend auf `Ausführen`.

::: info Hinweis

Eventuell weißt der Gruppenprozess auf Eingaben hin, die nicht den Vorgaben entsprechen - zum Beispiel, wenn bei einer konkreten eingegebenen Maßnahme ein *Freitext* erwartet wird.

:::
