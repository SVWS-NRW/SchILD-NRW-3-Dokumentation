# Einzelne Fächer bei einer Schülergruppe löschen

Entfernen Sie ausgewählte Unterrichtsfächer im angegebenen Schuljahr und Abschnitt. Über eine zusätzliche Option können kursgebundene Einträge geschützt werden.

[![Gruppenprozesse\_Fächer\_bei\_SchülerInnen\_löschen](/bilder/suchen-gruppenprozesse/gruppenprozesse-faecher-bei-schuelern-loeschen.png)](/bilder/suchen-gruppenprozesse/gruppenprozesse-faecher-bei-schuelern-loeschen.png)

*Gruppenprozesse\_Fächer\_bei\_SchülerInnen\_löschen*

Wählen Sie zuerst die gewünschte Schülergruppe aus. Öffnen Sie dann **Gruppenprozesse ➜ Fächer ➜ Einzelne Fächer bei Schülern löschen**.

Dieser Gruppenprozess ermöglicht das Löschen ganzer Unterrichtsfächer im jeweils ausgewählten Schuljahr und Abschnitt bei der selektierten Schülergruppe.

Das Häkchen, das ganz unten gesetzt werden kann, verhindert das versehentliche Löschen von Fächern, in denen Kurse zugewiesen sind. Ist das Häkchen gesetzt, werden nur Fächer ohne Kurseintrag gelöscht.  

::: example Beispiel

Dies kann notwendig sein, wenn wegen Veränderungen in der Unterrichtsverteilung Unterricht komplett entfällt.

Ein weiterer Anwendungsfall wäre es, über eine Stundentafel jeweils allen Schülern eines Jahrgangs die epochal unterrichteten Fächer zuzuweisen und dann bei der jeweils zutreffenden Gruppe das nicht belegte Fach zu löschen.

:::
