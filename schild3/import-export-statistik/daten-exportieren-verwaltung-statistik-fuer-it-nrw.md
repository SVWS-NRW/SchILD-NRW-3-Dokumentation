# Statistikdaten für ASDPC exportieren

::: info Hinweis – Geltungsbereich: ASDPC-Verfahren

Dieser Artikel beschreibt die Vorbereitung beziehungsweise Nutzung des bisherigen ASDPC-Verfahrens. Für die amtliche Erhebung **ab dem Schuljahr 2027/2028** ist die Umstellung auf das Statistikmodul des SVWS-Servers angekündigt. Beachten Sie den [offiziellen Zeitplan](https://www.svws.nrw.de/statistik/asdpc-svws-server) und die Vorgaben der jeweiligen Erhebung.

:::

Erstellen Sie die benötigten Statistikdateien für ASDPC. Prüfen Sie zuvor die Daten und kontrollieren Sie die ausgewählten Datensätze und Schülerzahlen.

Im Folgenden werden die Schritte beschrieben, welche die vier benötigten Exportdateien für ASDPC32 erstellen.

::: tip Tipp

Es ist sehr empfehlenswert, vor dem Export die *Gesamtprüfung der Daten* durchzuführen und alle für die Statistik relevanten von SchILD-NRW gefunden Fehler vor dem Export zu bereinigen.

:::

[![Auswahl der zu exportierenden Daten.](/bilder/import-export-statistik/verwaltung-statistikexport.png)](/bilder/import-export-statistik/verwaltung-statistikexport.png)

*Auswahl der zu exportierenden Daten.*

Rufen Sie das Exportfenster über *Verwaltung ➜ Statistik für IT.NRW* ➜ **Daten exportieren** auf.

Kontrollieren Sie, ob die Schülerzahlen Ihren Erwartungen entsprechen und wählen Sie dann die zu exportierenden Datensätze an.

- **SIM.txt**: Diese Datei enthält alle Daten zu den Schülern.
- **UVD.txt:** Enthält die Unterrichtsverteilung, also Angaben zur Klassen- und Kursstruktur.
- **LID.txt**: Diese Datei enthält die Daten zu den Lehrkräften und deren Einsätze.
- **ABI.txt**: Diese Datei enthält die Daten zum Abitur.

Nicht in allen Schulen werden je nach Arbeitsweise alle Dateien benötigt.  

[![Wählen Sie einen Speicherort für die Dateien.](/bilder/import-export-statistik/verwaltung-statistik-export-si-mtxt.png)](/bilder/import-export-statistik/verwaltung-statistik-export-si-mtxt.png)

*Wählen Sie einen Speicherort für die Dateien.*

Bestätigten Sie eventuelle Nachfragen, so dass Sie in den Export gelangen.

Wählen Sie nun einen Speicherort für die zu erzeugende Datei, hier im Beispiel wird die SIM.txt mit den Schülerdaten erzeugt.

::: danger Achtung

Benennen Sie die Dateien nicht um, obwohl dies hier möglich wäre.

:::

Klicken Sie dann auf `Speichern`.  

[![Vor jedem Export wird ein Hinweisfenster mit den Daten der von SchILD-NRW verwendeten Statistikdateien angezeigt. Bestätigen Sie mit OK, um den Export der jeweiligen Datei zu starten.](/bilder/import-export-statistik/verwaltung-statistik-export-nachfragen.png)](/bilder/import-export-statistik/verwaltung-statistik-export-nachfragen.png)

*Vor jedem Export wird ein Hinweisfenster mit den Daten der von SchILD-NRW verwendeten Statistikdateien angezeigt. Bestätigen Sie mit `OK`, um den Export der jeweiligen Datei zu starten.*

Bestätigen Sie auch die weiteren Rückfragen. Vergleichen Sie zuvor die angezeigte Version und das Datum der Statistikdateien mit dem Stand Ihres Statistikprogramms ASDPC.

Sollte es hier Abweichungen geben, bringen Sie bitte SchILD-NRW und das Statistikprogramm auf den jeweils aktuellen Stand.

Dieses Vorgehen wird für jede der zum Export ausgewählten Statistikdateien wiederholt.  

::: tip Richtig – Fertig

Ihre Dateien wurden exportiert und können nun im Statistikprogramm entsprechend des dortigen Verfahrens eingelesen werden.

:::
