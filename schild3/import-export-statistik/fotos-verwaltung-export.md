# Schülerfotos als Bilddateien exportieren

Speichern Sie die Fotos der ausgewählten Schülerinnen und Schüler in einem Zielordner. Wählen Sie dazu das gewünschte Dateinamensmuster.

[![Export der Fotos aus der Datenbank.](/bilder/import-export-statistik/export-fotos.png)](/bilder/import-export-statistik/export-fotos.png)

*Export der Fotos aus der Datenbank.*

Nach dem Aufruf des Menüpunktes *"Verwaltung ➜ Export ➜ Fotos"* werden Sie gebeten, einen Zielordner auszuwählen.

**Dateinamensmuster auswählen**

Weiterhin können Sie das Format des *Foto-Dateinamens* festlegen.  
Nach einer Bestätigung mit **Ok** werden dann alle Schülerfotos der gefilterten Schülermenge nach dem gewählten Muster gespeichert:

*NACHNAME_VORNAME_KLASSE.jpg*

*NACHNAME_VORNAME_GEBURTSDATUM.jpg*

*ID.jpg*

::: info Hinweis

Für den automatischen Foto-Import gibt es ein kostenpflichtiges Programm der Firma Ribeka.

:::
