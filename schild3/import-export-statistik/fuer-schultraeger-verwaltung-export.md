# Daten für den Schulträger verschlüsselt exportieren

Erstellen Sie den für das Schulträgermodul vorgesehenen Export. Wählen Sie Verschlüsselung und Kennwortverfahren und beachten Sie die getrennte Übermittlung eines individuellen Kennworts.

[![Starten des Exports an den Schulträger.](/bilder/import-export-statistik/export-schultraeger-1.png)](/bilder/import-export-statistik/export-schultraeger-1.png)

*Starten des Exports an den Schulträger.*

Über *Verwaltung ➜ Export* ➜ **Für Schulträger** können Sie einen Export für Daten an den Schulträger anstoßen.  

[![Einstellungen des Schulträger-Exports.](/bilder/import-export-statistik/export-schultraeger-2-optionen.png)](/bilder/import-export-statistik/export-schultraeger-2-optionen.png)

*Einstellungen des Schulträger-Exports.*

Wählen Sie zuerst ein **Ausgabeverzeichnis**.

Anschließend können unterschiedliche *Optionen* festgelegt werden.

**Verschlüsselungsverfahren wählen**

Wählen Sie die Art der Verschlüsselung.

- **Daten verschlüsselt mit Standardkenntwort** sorgt dafür, dass die Daten mit dem Schulträgermodul entschlüsselt werden können. In diesem Fall muss kein Kenntwort gesetzt und ausgetauscht werden.
- **Daten verschlüsselt mit individuellem Kennwort** lässt Sie ein eigenes Kennwort setzen. Dieses Kennwort muss dann auf sicherem Wege dem Schulträger mitgeteilt werden und darf keinesfalls zusammen mit einer eventuellen E-Mail mit verschickt werden, über die auch die Daten übermittelt werden. Das Kennwort soll modernen Standards in Länge und der Verwendung von Groß-, Kleinschreibung, Zahlen und Sonderzeichen entsprechen.

Damit Sie sicher sind, das Kennwort auch so wie gedacht einzutippen, lässt sich bei der Eingabe das **Kennwort anzeigen**.

Wurde der E-Mail-Versand in SchILD-NRW eingerichtet, lässt sich eine **E-Mailadresse** angeben, an welche der Export direkt versandt wird.

Schlussendlich wählen Sie, welche Daten exportiert werden sollen:

- **Alle Schüler** exportiert die komplette Schule.
- **Nur Schüler, die in der aktuellen Auswahl enthalten sind** exportiert die links angezeigten Schüler. Diese werden vor Aufrufen des Exportfensters über den Reiter *Schüler* gefiltert.

**Export starten** speichert eine Datei *\[Schulnummer\].zip* in das angegebene Verzeichnis.

Diese kann mit dem verwendeten Passwort beziehungsweise über das Schulträgermodul entpackt werden.

Das Format entspricht den Schnittstellendateien und kann in einem Tabellenkalkulationsprogramm weiterverarbeitet werden.
