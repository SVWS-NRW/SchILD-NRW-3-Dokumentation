# Daten für iServ exportieren

Erstellen Sie Exportdateien für iServ aus der gewünschten Schüler- und Unterrichtsauswahl. Prüfen Sie die bereitgestellten Optionen mit der für den Import verantwortlichen Person.

Über diese Auswahl lassen sich Daten der Personen der Schule und Unterrichtsdaten so exportieren, dass sie von iServ wieder importiert werden und dort verwendet werden können.

::: info Hinweis

iServ das Produkt eines kommerziellen Anbieters und wird in einigen Schulen in NRW eingesetzt.

:::

## Export aus SchILD

[![Exportfenster unter Verwaltung ➜ Export ➜ iServ.](/bilder/import-export-statistik/verwaltung-export-i-serv.png)](/bilder/import-export-statistik/verwaltung-export-i-serv.png)

*Exportfenster unter Verwaltung ➜ Export ➜ iServ.*

Bei Aufruf des Exportfensters können einige Auswahlen vorgenommen werden. Unter **Status** und **Klassen** ist anzugeben, welche Schüler exportiert werden.

Oben rechts ist die Lernplattform zu wählen, die verwendet wird. Diese Lernplattform muss unter *Kataloge ➜ Lernplattformen* eingerichtet werden.

Stimmen Sie mit der zuständigen Administration ab, welche Bezeichnungen Ihre Schule in der Lernplattform verwendet. Klären Sie mit dem Anbieter beziehungsweise der für den Import verantwortlichen Person, welche Daten und Einstellungen für die Exportdatei benötigt werden.

Das gilt insbesondere für die Gruppen, die im Zielsystem angelegt werden sollen.

Schlussendlich ist jeweils das **Exportverzeichnis** für die **Schülerdaten** und die **Lehrerdaten** anzugeben.

Beide Exporte werden getrennt durch jeweils einen Klick auf `Export starten` angestoßen.  

::: info Hinweis

Während des Exports kann es unter Umständen zu Fehlern kommen, zum Beispiel auf Grund von nicht oder falsch angelegter E-Mail-Adressen der Personen der Schule.

:::

## Import in iServ

Bitte nutzen Sie die Dokumentation und den Support Ihrer Lernplattform für den Import. Klären Sie bitte ebenfalls mit dem Anbieter, welche Optionen beim Export zu wählen sind, um die Daten wie beabsichtigt verwenden zu können.

Alle ausgewählten **Schülerstatus** werden berücksichtigt. Im zweiten Halbjahr werden Epochenfächer beim Export zu IServ und Microsoft 365 nicht mehr berücksichtigt. Kontrollieren Sie bei abweichenden Gruppen deshalb auch Programmversion und Exportabschnitt.
