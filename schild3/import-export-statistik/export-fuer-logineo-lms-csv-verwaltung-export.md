# Daten für LOGINEO NRW LMS als CSV exportieren

Wählen Sie Schülergruppe, Lernplattform und Exportumfang für LOGINEO NRW LMS. Dieser CSV-Export unterscheidet sich vom XML-Verfahren für LOGINEO NRW.

[![Export der Daten von SchILD-NRW nach Logineo LMS als .csv-Datei. Das orange Auswahlfenster ist mit einem Klick auf die rechte Maustaste zu öffnen.](/bilder/import-export-statistik/verwaltung-export-logineo-lms-csv.png)](/bilder/import-export-statistik/verwaltung-export-logineo-lms-csv.png)

*Export der Daten von SchILD-NRW nach Logineo LMS als .csv-Datei. Das orange Auswahlfenster ist mit einem Klick auf die `rechte Maustaste` zu öffnen.*

Öffnen Sie **Verwaltung → Export → Logineo LMS (CSV)**, um Daten für LOGINEO NRW LMS bereitzustellen. **CSV** bezeichnet eine Textdatei, in der Trennzeichen die Daten in Spalten gliedern.

Wählen Sie über **Status** und **Klassen** die Schülermenge aus, die exportiert werden soll.

**Exportumfang und Gruppen festlegen**

Wählen Sie oben rechts die **Lernplattform** aus. Diese muss zuvor unter **Kataloge → Lernplattform** eingerichtet worden sein. Auf der rechten Seite legen Sie die weiteren Exportdetails fest.

Wählen Sie die Daten und vor allem die Gruppen, wie es an der Schule geplant ist.

Abschließend ist festzulegen, ob die **Schüler-** und/oder die **Lehrerdaten** exportiert werden sollen und ob für die Nutzer **Initialkennworte erzeugt** und dann **ausgegeben** werden.

Konsultieren Sie hierzu bitte auch die Dokumentation von Logineo LMS.  

::: info Hinweis

Beachten Sie den Unterschied von *Logineo NRW LMS* und *Logineo NRW*. Diese Angebote lesen jeweils unterschiedliche Exportdaten von SchILD-NRW ein.

:::

Konsultieren Sie zum Import die Dokumentation von Logineo LMS.
