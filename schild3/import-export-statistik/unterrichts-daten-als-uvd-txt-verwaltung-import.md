# Unterrichtsdaten aus UVD.TXT importieren

Der UVD-Import verbindet die Unterrichtsplanung im Stundenplanprogramm mit der weiteren Datenpflege in SchILD-NRW. Die folgenden Schritte erläutern die Vorbereitung und die Übernahme der Exportdatei.

## Exportdatei bereitstellen

Übernehmen Sie die aus einem Stundenplanprogramm exportierte Grund-Unterrichtsverteilung. Individuelle Fach- und Kurszuweisungen sind anschließend gesondert zu ergänzen.

[![Auswahl des Speicherorts einer UVD.TXT.](/bilder/import-export-statistik/import-uvd.png)](/bilder/import-export-statistik/import-uvd.png)

*Auswahl des Speicherorts einer UVD.TXT.*

Bei einem Einsatz eines Stundenplanprogramms (WinPlan, Untis...) können die klassenrelevanten Daten der Unterrichtsverteilung in eine Datei *UVD.TXT* exportiert werden.

Öffnen Sie **Verwaltung → Import → Unterrichts-Daten (als UVD.TXT)**. Der Import übernimmt die grundlegende Unterrichtsverteilung (**Grund-UVD**) in das aktuelle Halbjahr der Schülerinnen und Schüler.

Individuelle Fach- und Kurszuweisungen müssen jedoch gesondert nach dem Import durchgeführt werden.

## UVD-Datei auswählen und übernehmen

Geben Sie nach dem Anwählen des Menüpunktes den Speicherpfad der UVD.TXT an.  

::: info Hinweis

Eine Aktivierung der Option **In Sekundarstufe II Kurse anlegen** ist eventuell nicht sinnvoll, wenn diese durch den Import aus den Programmen LuPO bzw. Kurs42 übernommen werden.

:::
