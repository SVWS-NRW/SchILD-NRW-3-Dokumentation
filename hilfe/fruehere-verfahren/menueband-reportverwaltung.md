# Das frühere Menüband der Reportverwaltung

Dieser Artikel beschreibt das frühere, im Wiki dokumentierte Menüband der Reportverwaltung. Für die Oberfläche von SchILD-NRW 3.6.0 verwenden Sie [Das Menüband der Reportverwaltung](/reporting/reportverwaltung/menueband-reportverwaltung).

[![Das frühere Menüband in der Reportverwaltung.](/bilder/reportverwaltung/reports-menueband-uebersicht.png)](/bilder/reportverwaltung/reports-menueband-uebersicht.png)

*Das frühere Menüband in der Reportverwaltung.*

## Reportbearbeitung

[![Der Bereich Reportbearbeitung bietet von Windows gewohnte Funktionen.](/bilder/reportverwaltung/reports-menueband-bearbeiten.png)](/bilder/reportverwaltung/reports-menueband-bearbeiten.png)

*Der Bereich Reportbearbeitung bietet von Windows gewohnte Funktionen.*

| Frühere Funktion | Wirkung |
| --- | --- |
| **Neuen Report erzeugen** | Erstellt einen neuen, leeren Report im ausgewählten Ordner. |
| **Bearbeiten** | Öffnet den ausgewählten Report im Reporteditor. |
| **Kopieren** | Merkt den ausgewählten Report zum Kopieren vor. **Einfügen** erzeugt eine Kopie im Zielordner. |
| **Ausschneiden** | Merkt den Report zum Verschieben vor. Beim Einfügen an anderer Stelle wird das Original entfernt. |
| **Einfügen** | Fügt einen zum Kopieren oder Ausschneiden vorgemerkten Report ein. |

## Allgemeine Reportfunktionen

[![Der Bereich Allgemeine Reportfunktionen steuert im Hintergrund laufende Technik.](/bilder/reportverwaltung/reports-menueband-allg-fkt.png)](/bilder/reportverwaltung/reports-menueband-allg-fkt.png)

*Der Bereich Allgemeine Reportfunktionen steuert im Hintergrund laufende Technik.*

| Frühere Funktion | Wirkung |
| --- | --- |
| **Verzeichnisbaum aktualisieren** | Liest die Ordnerstruktur neu ein, wenn Ordner oder Reports parallel im Windows-Explorer geändert wurden. |
| **Abfragen aktualisieren** | Aktualisiert bereits geladene Katalogdaten. Einige Tabellen, etwa die Fächerkataloge, wurden beim Programmstart in die Reportumgebung geladen. Eine später geänderte Fachbezeichnung konnte deshalb erst nach dem Aktualisieren in der Reportausgabe erscheinen. |
| **Druckerliste aktualisieren** | Liest die von Windows bereitgestellten Drucker neu ein. |
| **Info zu Standardformularen** | Zeigt die als Standard festgelegten Reports für Stammblatt und Schulbescheinigung. |
| **Info über Datenquellen** | Zeigt verfügbare Datenquellen, ihre Struktur und Datenbankfelder. |

Die Standardformulare wurden mit einem Rechtsklick auf den jeweiligen Report festgelegt. Anschließend ließen sich Stammblatt und Schulbescheinigung unter **Individualdaten I ➜ Drucken** aufrufen.

## Ansicht und ausgewähltes Schuljahr

[![Die Bereiche Ansicht und Ausgewähltes Schuljahr.](/bilder/reportverwaltung/reports-menueband-ansichtund-abschnitt.png)](/bilder/reportverwaltung/reports-menueband-ansichtund-abschnitt.png)

*Die Bereiche Ansicht und Ausgewähltes Schuljahr.*

**Details** zeigte Dateiname, Dateigröße sowie Datum und Uhrzeit der letzten Änderung; **Liste** zeigte nur den Dateinamen. Der Zeitstempel half, den Stand einer Reportdatei zu erkennen.

Über **Schuljahr/Abschnitt** wurde der Lernabschnitt als Datengrundlage ausgewählt. So konnte beispielsweise nach dem Abschnittswechsel noch ein Abgangszeugnis mit den Daten des vorherigen Abschnitts ausgegeben werden.

Anschließend musste wieder der aktuelle Abschnitt eingestellt werden, damit weitere Reports nicht mit Daten des falschen Abschnitts erzeugt wurden. Diesen Arbeitsablauf erläutert [Daten aus zurückliegenden Abschnitten drucken](/reporting/reportverwaltung/daten-aus-zurueckliegenden-abschnitten-drucken).
