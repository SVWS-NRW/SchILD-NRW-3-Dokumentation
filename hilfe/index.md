## An der Dokumentation mitarbeiten

[Mitarbeiten](/hilfe/mitarbeiten) erklärt den Einstieg und zeigt die `CONTRIBUTING.md` des Repositorys. Die bebilderten Anleitungen führen Sie mit einem eigenen Arbeitsbranch bis zum Pull Request gegen `dev`:

- [Mit VS Code im Browser bearbeiten](/hilfe/vscode-editor) für längere Änderungen und mehrere Dateien.
- [Mit dem GitHub-Editor bearbeiten](/hilfe/github-editor) für kleine Korrekturen an einer Datei.

[Artikel schreiben und bearbeiten](/hilfe/artikel-schreiben) erläutert die gemeinsamen Schreibregeln. [Markdown und Gestaltung](/hilfe/markdown-und-gestaltung) zeigt kopierbare Bausteine mit ihrer Darstellung.
