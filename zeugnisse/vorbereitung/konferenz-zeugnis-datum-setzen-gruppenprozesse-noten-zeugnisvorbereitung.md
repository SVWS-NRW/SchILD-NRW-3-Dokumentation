# Konferenz- und Zeugnisdatum setzen

Tragen Sie Konferenz- und Zeugnisdatum für die ausgewählte Schülergruppe im gewünschten Lernabschnitt ein.

[![Konferenz- und Zeugnisdatum gruppenweise setzen.](/bilder/vorbereitung/gruppenprozesse-noten-zeugnisvorbereitung-konferenz-zeugnisdatum-setzen.png)](/bilder/vorbereitung/gruppenprozesse-noten-zeugnisvorbereitung-konferenz-zeugnisdatum-setzen.png)

*Konferenz- und Zeugnisdatum gruppenweise setzen.*

**Datum für die ausgewählte Gruppe setzen**

Dieser Gruppenprozess ermöglicht das automatische Setzen des **Konferenz- und Zeugnisdatums** im ausgewählten Lernabschnitt.  

::: info Hinweis

Der beschriebene Gruppenprozess bezieht sich immer auf die im Container angezeigte Schülermenge. Sollen für unterschiedliche Schülermengen, zum Beispiel jahrgangsweise, verschiedene Konferenz-/Zeugnisdaten gesetzt werden, so muss vor Beginn dieses Gruppenprozesses eine entsprechende Auswahl über den Schnellfilter erfolgen.

:::
