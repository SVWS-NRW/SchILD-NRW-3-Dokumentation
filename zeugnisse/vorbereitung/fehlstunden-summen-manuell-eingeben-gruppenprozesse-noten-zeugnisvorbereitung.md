# Gesamtfehlstunden gruppenweise eingeben

Erfassen Sie Gesamtfehlstunden und unentschuldigte Fehlstunden für die ausgewählte Gruppe. Voraussetzung ist der Eingabemodus für die direkte Erfassung von Gesamtfehlstunden.

Dieser Gruppenprozess ermöglicht es, für die gefilterte Schülermenge Gesamtfehlstunden einzugeben.

**Fehlstunden erfassen und übernehmen**

Tragen Sie im folgenden Fenster die **gesamten Fehlzeiten** und die **unentschuldigten Fehlstunden** in die Tabellenfelder ein.

Nach Abschluss der Eingabe werden die Daten durch Klick auf die Schaltfläche `In die Datenbank übernehmen` gespeichert.

Die Fehlstunden finden sich anschließend unter *Schüler ➜ Akt. Halbjahr ➜ Allgemeine Angaben* in den beiden Feldern für die Fehlstunden.

::: info Hinweis

Wählen Sie zuerst unter **Verwaltung → Einstellungen → Globale Einstellungen → Fächer, Noten** im Bereich **Eingabemodus** den **Modus für Gesamtstunden**. Stellen Sie dort **Eingabe der Gesamt-Fehlstunden** ein. In diesem Modus erfassen Sie bereits aufsummierte Fehlstunden.

:::
