# Einen Lernabschnitt mit seinen Leistungsdaten löschen

Löschen Sie einen ausgewählten Lernabschnitt einschließlich seiner Leistungsdaten. Beachten Sie besonders die Folgen für Klasse und Jahrgang, wenn der letzte aktuelle Abschnitt entfernt wird.

::: warning Wichtig

**Dieses Feature verhält sich anders als in SchILD2:** 

Wenn Sie den **letzten aktuellen Abschnitt** löschen, fehlen anschließend Klasse, Jahrgang und weitere Angaben im Schülercontainer. Diese Angaben sind in SchILD-NRW 3 im letzten aktuellen Lernabschnitt gespeichert.

Achten Sie darauf, die Löschoperationen so auszuführen, dass bei den Schülern, die den letzten Abschnitt gelöscht bekommen, im Anschluss die fehlenden Daten im *dann* letzten Abschnitt eingetragen werden können. D.h.: Löschen Sie jahrgangsweise oder sogar über mehrere Jahrgänge hinweg, müssen die Schüler einzeln den Klassen neu zugeordnet werden!

:::

[![Löschen von Lernabschnitten für eine ausgewählte Schülergruppe.](/bilder/vorbereitung/gruppenprozesse-abschnittsdaten-loeschen.png)](/bilder/vorbereitung/gruppenprozesse-abschnittsdaten-loeschen.png)

*Löschen von Lernabschnitten für eine ausgewählte Schülergruppe.*

Dieser Gruppenprozess dient der Löschung ganzer Abschnitte.

::: info Hinweis

Normalerweise sollte dies nicht nötig sein, falls doch, so führt dieser Gruppenprozess zum Ziel.

:::

Im sich öffnenden Fenster muss das zu *löschende Schuljahr mit dem zu löschenden Abschnitt* ausgewählt werden.

Klicken auf `OK` bewirkt dann, dass bei allen im Container ausgewählten Schülern der gesamte Inhalt dieses Abschnittes, inklusive aller Leistungsdaten wie Fächerzuordnungen mit ihren Noten, gelöscht wird.

::: info Hinweis

Wie bei allen anderen Löschoperationen auch sollte zuvor eine Datensicherung durchgeführt werden.

:::
