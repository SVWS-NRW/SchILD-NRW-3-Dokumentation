# Zugeordnete Zeugnisformulare gesammelt drucken

Drucken Sie die zuvor zugeordneten Zeugnisvorlagen für eine gefilterte Schülergruppe. Gruppen und Auswahlhaken helfen, die passenden Formulare festzulegen.

[![Drucken von über den Katalog zugeordneten Zeugnisformularen.](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-1-auswahl.png)](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-1-auswahl.png)

*Drucken von über den Katalog zugeordneten Zeugnisformularen.*

Wurden über *Kataloge ➜ Zeugnisformulare zuordnen* Zeugnis-Reports einzelnen Jahrgängen oder Abschlüssen zugeordnet, können diese Zeugnisse in SchILD-NRW 3 über diesen Gruppenprozess gesammelt gedruckt werden.

Filtern Sie zunächst die Schülermenge, für die Zeugnisse gedruckt werden sollen. Nutzen Sie hierzu den *Filter I*.

::: example Beispiel

Filtern Sie an einer Gesamtschule zunächst alle Schülerinnen und Schüler der Jahrgangsstufe 10 mit Hauptschulabschluss und drucken Sie anschließend diese Zeugnisse. Danach filtern Sie auf die Schülerinnen und Schüler mit mittlerem Schulabschluss (MSA) und drucken die entsprechenden Zeugnisse.

:::

Wechseln Sie anschließend zu *Gruppenprozesse ➜ Noten-/Zeugnisvorbereitungen ➜ Zugeordnete Zeugnisse drucken*, um den Gruppendruck zu starten.

Im Auswahlfenster werden alle Einträge aus dem Katalog angezeigt. Wenn im Katalog Gruppen definiert wurden, kann oben rechts im Fenster nach einer Gruppe gefiltert werden.  

::: example Beispiel

An einer Gesamtschule bietet es sich an, Gruppen wie *Sekundarstufe I* und *Sekundarstufe II* beziehungsweise *Oberstufe* zu verwenden. Wenn zusätzlich andere Reports wie Leistungsübersichten (zum Beispiel für AOSF-Schülerinnen und -Schüler) über diesen Gruppenprozess gedruckt werden, können dafür eigene Gruppen angelegt werden.

:::

Aktivieren Sie über die Auswahlhaken die Zeugnisse, die für die aktuell gefilterte Schülergruppe erzeugt werden sollen. Über *Alle aktivieren* und *Alle deaktivieren* können sämtliche Haken gesetzt oder entfernt werden.

Klicken Sie anschließend in der Kopfzeile des Fensters auf **Ausgabe starten**, um den Druckprozess zu beginnen.  

[![Diese Warnmeldung sollte beachtet werden.](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-2-warnung.png)](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-2-warnung.png)

*Diese Warnmeldung sollte beachtet werden.*

Es erscheint eine Warnmeldung, dass der Vorgang einige Zeit in Anspruch nehmen kann. Starten Sie keine weiteren Zeugnisdruck-Gruppenprozesse, solange der aktuelle Prozess noch läuft.  

[![Der gewohnte Dialog zum Drucken von Reports.](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-3-druckdialog.png)](/bilder/vorbereitung/gruppenprozesse-zeugeordnete-zeugnisse-drucken-3-druckdialog.png)

*Der gewohnte Dialog zum Drucken von Reports.*

Anschließend öffnet sich der gewohnte Report-Druckdialog. Dort können Optionen wie *Vorschau*, *Druck* und *Archivierung* ausgewählt werden.

Achten Sie darauf, dass der Druck für **die ganze Gruppe** aktiviert ist.
