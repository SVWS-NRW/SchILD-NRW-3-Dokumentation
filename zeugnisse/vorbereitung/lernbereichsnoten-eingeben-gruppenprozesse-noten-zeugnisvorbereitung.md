# Lernbereichsnoten gruppenweise eingeben

Erfassen Sie die für die Abschlussberechnung benötigten Lernbereichsnoten für eine Schülergruppe und übernehmen Sie diese in die Datenbank.

[![Gruppenweise Lernbereichsnoten für den HA eintragen.](/bilder/vorbereitung/gruppenprozesse-lernbereichsnoten.png)](/bilder/vorbereitung/gruppenprozesse-lernbereichsnoten.png)

*Gruppenweise Lernbereichsnoten für den HA eintragen.*

Der *Gruppenprozess ➜ Noten, Zeugnisvorbereitung* ➜ **Lernbereichsnoten eingeben** ist geeignet, um die für den *Hauptschulabschluss* relevanten Lernbereichsnoten für eine größere Schülergruppe einzugeben.

Es öffnet sich eine Liste mit den auswählten Schülern im Schülercontainer.

Tragen Sie die Lernbereichsnoten ein und klicken Sie dann auf `In Datenbank übernehmen`.

Ein Klick auf `Abbrechen` beendet den Dialog, ohne Änderungen an der Datenbank auszuführen.

Ohne den Gruppenprozess können Lernbereichsnoten für jeden Schüler einzeln im unteren Bereich auf der Karteikarte *Schüler ➜ Akt. Halbjahr ➜ Allgemein* eingegeben werden.

::: info Hinweis

Diese Noten müssen für den Bereich *Gesellschaftswissenschaften* und *Naturwissenschaften* eingetragen sein, damit Abschlussberechnungen bei Schülern mit Hauptschulabschluss möglich sind.

:::

::: tip Tipp

Lassen Sie zunächst den Gruppenprozess Versetzungs-/Abschluss-Berechnung durchlaufen und merken Sie sich die Schüler, bei denen angegeben wird, dass eine Berechnung wegen fehlender Lernbereichsnoten nicht möglich ist. So minimieren Sie die Anzahl der einzutragenden Lernbereichsnoten. Nehmen Sie hier auch im Reiter *Auswahl* den *Schülerfilter* zur Kenntnis.

:::
