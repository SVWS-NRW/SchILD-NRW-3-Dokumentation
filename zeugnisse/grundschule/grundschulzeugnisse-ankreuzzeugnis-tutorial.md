# Ankreuzzeugnisse für die Grundschule erstellen

Aktivieren Sie die betreffenden Klassen und definieren Sie Kompetenzen und Bewertungsstufen. Anschließend weisen Sie die Kompetenzen den Leistungsdaten zu.

## 1. Klassen und Leistungsdaten vorbereiten

Zuerst muss die Schule für das Eintragen von Leistungsdaten vorbereitet werden. Folgen Sie hierzu der Anleitung im Artikel zur [Vorbereitung von Grundschulzeugnissen](/zeugnisse/grundschule/grundschulzeugnisse-vorbereitung-fuer-text-und-ankreuzzeugnisse-tutorial).

[![Schalten Sie unter Kataloge in der Klassen- Versetzungstabelle die Verwendung von Ankreuzkompetenzen klassenweise frei.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-kompetenzen-freischalten.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-kompetenzen-freischalten.png)

*Schalten Sie unter Kataloge in der **Klassen- Versetzungstabelle** die Verwendung von Ankreuzkompetenzen klassenweise frei.*

Weiterhin muss bei einer Klasse die Verwendung von Ankreuzkompetenzen aktiviert sein. Gehen Sie hierzu über *Kataloge* in die **Klassen- und Versetzungstabelle**.

Klicken Sie auf die Klassen, in der die Ankreuzkompetenzen verwendet werden sollen und setzen Sie den Haken bei **In dieser Klasse werden Ankreuzzeugnisse verwendet**.

[![Der neue Schalter unter Schüler ➜ Akt. Halbjahr zum Eintragen von Ankreuzkompetenzen.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-kompetenzen-freischalten-schueler-schalter.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-kompetenzen-freischalten-schueler-schalter.png)

*Der neue Schalter unter Schüler ➜ Akt. Halbjahr zum Eintragen von Ankreuzkompetenzen.*

Nun steht unter *Schüler ➜ Akt. Halbjahr* für Schüler dieser Klasse der neue Reiter **Kompetenzen für Ankreuzzeugnisse** zur Verfügung und die Kompetenzen können auch per Gruppenprozess zugewiesen werden.

Hierzu folgt mehr weiter unten.

## 2. Kompetenzen definieren

[![Anlegen und Bearbeiten von Ankreuzkompetenzen über Kataloge ➜ Angaben für Ankreuzzeugnisse.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-katalog-anlegen.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-katalog-anlegen.png)

*Anlegen und Bearbeiten von Ankreuzkompetenzen über Kataloge ➜ **Angaben für Ankreuzzeugnisse**.*

Die zur Wahl stehenden Ankreuzkompetenzen werden über den *Kataloge* ➜ **Angaben für Ankreuzzeugnisse** erzeugt und dann bearbeitet.

Wählen Sie ein **Fach** und einen **Jahrgang**, für den eine Kompetenz zur Verfügung stehen soll.

Kompetenzen werden dann über das **+** bzw. das **-** erzeugt beziehungsweise entfernt.

Wählen Sie auch, für welches **Halbjahr** - oder für beide - die Kompetenz bewertbar sein soll.

Weiterhin kann über die Zahl rechts die **Sortierreihenfolge** festgelegt werden. Die Sortierung bestimmt, in welcher Reihenfolge die Kompetenzen auf dem Zeugnis ausgedruckt werden.

::: info Hinweis

- Für den Jahrgang *E3* werden keine Kompetenzen angelegt. In diesem Jahrgang werden die für den Jahrgang *E2* definierten Kompetenzen verwendet.
- Obwohl *ASV - "Arbeits- und Sozialverhalten"* kein tatsächliches Fach ist, wird es hier wie eines behandelt.

:::

::: warning Wichtig

Die zur Bewertung genutzten Kompetenzen werden über die zuständigen Konferenzen, Fach- bzw. Schulkonferenzen, beschlossen.

:::

### Import und Export

[![Über den Schalter Import kann eine Excel-Datei mit Vorlagen ausgewählt werden.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-import.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-import.png)

*Über den Schalter **Import** kann eine Excel-Datei mit Vorlagen ausgewählt werden.*

Verfügen Sie über eine Datei Excel-Datei mit Vorlagen zum Import, klicken Sie auf `Import` und wählen Sie diese Datei aus. Die Kompetenzen stehen nun in SchILD zur Verfügung.

Die hier verwendete Datei wurde im Zeugnisbereich auf der Seite des [MSB für Schulverwaltungssoftware](<https://www.svws.nrw.de>) heruntergeladen. An gleicher Stelle finden Sie ebenfalls eine leere Excel-Datei, die für das Befüllen mit eigenen Einträgen vorbereitet wird.

Entsprechend können Floskeln zur Weitergabe und -verarbeitung auch **exportiert** werden.

Klicken Sie hierzu auf `Export` und wählen Sie einen Dateispeicherort.

::: tip Tipp

Um Ankreuzkompetenzen beziehungsweise Textbausteine für einen anderen Jahrgang einzugeben, können Sie die Arbeit sparen, indem Sie die Eingabe einmal für einen Jahrgang vornehmen, dann exportieren und in einem Tabellenverarbeitungsprogramm ihrer Wahl die Zeilen kopieren beziehungsweise den Jahrgang ändern. Dann nehmen Sie einen erneuten Export vor.

:::

::: warning Wichtig

Bitte beachten Sie, dass Floskeln, Ankreuzkompetenzen und Textbausteine - selbst erstellt oder als Import - nicht einfach verwendet werden können. Die Formulierungen müssen in den entsprechenden Fach- und Schulkonferenzen genehmigt werden.

:::

::: info Hinweis

- Fachfloskeln und ähnliche Einträge werden für den Jahrgang *E3* nicht eingegeben. Hier werden die Floskeln des Jahrgangs *E2* verwendet.
- Sie können Floskeln mit einem Doppelklick direkt in das Textfenster übernehmen.
- Wenn das *Kürzel* mit einem **\#** beginnt, kann eine Floskel auch über das Eintippen *"#KÜRZEL"* eingegeben werden.
- Bei der Eingabe von Floskeln kann der Haken bei **Mehrfache Nennung des Vornamens vermeiden** gesetzt werden. Das erste Vorkommen des Platzhalters *\$Vorname\$* wird dann zum Vornamen, folgende Nennungen werden zu *er* oder *sie*.

:::

### Unterkategorien

Zu Fächern können auch Unterkategorien gebildet werden. So könnten die Kompetenzen in *ASV* in die beiden Unterkategorien *"Lern- und Leistungsbereitschaft* und *Zuverlässigkeit und Sorgfalt* eingeteilt werden.

Eine Unterkategorie wird durch einen Doppelpunkt **:** kenntlich gemacht. Hierbei ist alles vor dem Doppelpunkt die Unterkategorie, alles danach die Kompetenz.

     Lern- und Leistungsbereitschaft: ... hält sich an Regeln und Vereinbarungen.
     Lern- und Leistungsbereitschaft: ... arbeitet auch längere Zeit konzentriert und zielstrebig.
     Lern- und Leistungsbereitschaft: beteiligt sich interessiert und engagiert am Unterricht.
     Zuverlässigkeit und Sorgfalt: ... erscheint pünktlich zum Unterricht.
     Zuverlässigkeit und Sorgfalt: ... führt Hefte und Vorlagen nach Vorgaben ordentlich.
     Zuverlässigkeit und Sorgfalt: ... bietet anderen Hilfe an und kann selber Hilfe annehmen.

[![Im fertigen Zeugnis erscheinen hier erst die Kompetenzen, die ohne Kategorie sind. Dann werden sie nach den Unterkategorien gruppiert. Hier im Beispiel ist ebenfalls zu sehen, dass bei entsprechender pädagogischer Entscheidung der Schule auch mehrere Haken gesetzt werden dürfen (Orange). Wurde kein Haken bei einer Kategorie gesetzt, ist diese durchstrichen (Blau).](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-unterkategorien-zeugnis.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-unterkategorien-zeugnis.png)

*Im fertigen Zeugnis erscheinen hier erst die Kompetenzen, die ohne Kategorie sind. Dann werden sie nach den Unterkategorien gruppiert. Hier im Beispiel ist ebenfalls zu sehen, dass bei entsprechender pädagogischer Entscheidung der Schule auch mehrere Haken gesetzt werden dürfen (Orange). Wurde kein Haken bei einer Kategorie gesetzt, ist diese durchstrichen (Blau).*

Wurden Unterkategorien gesetzt, führt dies dazu, dass unterhalb von ASV die Unter-Kompetenzen erst unter **Lern- und Leistungsbereitschaft** und dann als **Zuverlässigkeit und Sorgfalt** gruppiert werden.

Hier im Beispiel wurde die Sortierung so gewählt, dass alle Kompetenzen ohne Kategorie zuerst erscheinen.

### Kompetenzstufen definieren

[![Benennen Sie Ihre Kompetenzbezeichnungen. Es können vier oder fünf Stufen definiert werden. Weiterhin ist hier die Bezeichnung für frei definierbare Zeugnisrubrik benennbar.](/bilder/unterricht-kataloge/tutorials-gs-ankreuzzeugnisse-kompetenzen-benennen.png)](/bilder/unterricht-kataloge/tutorials-gs-ankreuzzeugnisse-kompetenzen-benennen.png)

*Benennen Sie Ihre Kompetenzbezeichnungen. Es können vier oder fünf **Stufen** definiert werden. Weiterhin ist hier die **Bezeichnung für frei definierbare Zeugnisrubrik benennbar.***

Unterhalb der Kompetenzen findet sich ein Bereich, in dem die vergebenen **Kompetenzstufen** definiert werden. Es sind maximal fünf Stufen möglich.

::: info Hinweis

Wurde für die fünfte Stufe kein Text vergeben sondern frei gelassen, werden auch nur vier Spalten zum ankreuzen angezeigt.

:::

### Anzeigen einer Legende

In der *AnkreuzZeugniseinstellungen.ini* lässt sich eine Legende ein- und ausblenden, in der Sie die Kompetenzstufen erläutern können.

     ; - Semikolon entfernen, um Kompetenzerläuterungen mit auszugeben
     ; KompetenzErlaeuterung

Entfernen Sie das Semikolon vor der Zeile mit *"KompetenzErlauterung"* und speichern Sie die Datei, wird die in der Datei *\_Kompetenz_Erlaeuterung.rtm* aufgeführte Legende ausgegeben. Diese Datei lässt sich vom Report-Explorer aus aufrufen und bearbeiten.

### Eine frei definierbare Zeugnisrubrik verwenden

[![Über das Pseudo-Fach Sonstiges lassen sich Ankreuzkompetenzen für die frei definierbare Zeugnisrubrik anlegen.](/bilder/unterricht-kataloge/tutorials-gs-ankreuzzeugnisse-frei-definierbares-sonstiges.png)](/bilder/unterricht-kataloge/tutorials-gs-ankreuzzeugnisse-frei-definierbares-sonstiges.png)

*Über das Pseudo-Fach Sonstiges lassen sich Ankreuzkompetenzen für die frei definierbare Zeugnisrubrik anlegen.*

Weiterhin lässt sich eine **frei definierbare Zeugnisrubrik** anlegen.

Wurde hier eine Kategorie definiert, können die dem zugeordneten Kompetenzen nun über das Pseudo-**Fach** *Sonstiges* wie üblich erzeugt werden.

Auch hier lassen sich Zeilenumbrüche mit einem **\#** erzwingen (siehe das Unterkapitel unten).

### Zeilenumbrüche

[![Zwei der Kompetenzen sind sehr lang. In der oberen der beiden langen Einträge wurde mit einem # ein Zeilenumbruch erzeugt.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-zeilenumbruch.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-zeilenumbruch.png)

*Zwei der Kompetenzen sind sehr lang. In der oberen der beiden langen Einträge wurde mit einem **#** ein Zeilenumbruch erzeugt.*

Bei den Kompetenzen werden für mehrzeilige Einträge Zeilenumbrüche automatisch vorgenommen. Das Ergebnis sieht häufig nicht gut aus, da auch ein Versatz vor der zweiten Zeile fehlt.

Mit einem Doppelkreuz (oder auch Raute) **\#** lässt sich ein Zeilenumbruch erzwingen, dem auch in der zweiten Zeile ein Versatz vorgestellt wird.

Ebenso kann in den *Beschreibungen der Kompetenzstufen* ein zweizeiliger Eintrag mit erzwungenem Zeilenumbruch gesetzt werden.

## 3. Kompetenzen über Leistungsdaten zuweisen

Damit Ankreuzkompetenzen zugewiesen werden können, müssen zuerst die Fächer in den individuellen Leistungsdaten bei den Schülern hinzugefügt worden sein. Dies geht individuell über *Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten* oder besser und für große Schülergruppen, zum Beispiel klassenweise, über *Stundentafeln*.

Lesen Sie hierzu das Tutorial zur [Vorbereitung von Grundschulzeugnissen](/zeugnisse/grundschule/grundschulzeugnisse-vorbereitung-fuer-text-und-ankreuzzeugnisse-tutorial).

Die für eine *Kombination aus Fach und Jahrgang* definierten Ankreuzkompetenzen lassen sich dann den individuellen Leistungsdaten der Schüler im Aktuellen Lernabschnitt per Gruppenprozess zuweisen. Gehen Sie über *Gruppenprozesse ➜ Noten, Zeugnisvorbereitung* ➜ **Ankreuzkompetenzen eintragen**.

[![Die Kompetenzen können nun fachweise in Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten ➜ Kompetenzen für Ankreuzzeugnisse gesetzt werden.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-leistungsdaten.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-leistungsdaten.png)

*Die Kompetenzen können nun fachweise in Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten ➜ **Kompetenzen für Ankreuzzeugnisse** gesetzt werden.*

Die definierten Ankreuzkompetenzen werden nun zugewiesen und können dann über *Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten* ➜ **Kompetenzen für Ankreuzzeugnisse** fachweise gesetzt werden.

Im Screenshot sind die Kompetenzen für das *Arbeits- und Sozialverhalten* zu sehen. Öffnen und schließen Sie die Kompetenzen für jedes Fach mit einem Klick auf das "**-**" vor dem Fach.

::: info Hinweis

1.  Es ist möglich, auch mehrere Kompetenzstufen anzuklicken.
2.  Wird bei einer Kompetenz kein Haken gesetzt, werden alle Checkboxen auf dem Zeugnis durchstrichen.

:::

::: tip Tipp

Ist das Feld zu klein, ziehen sie das übergeordnete Feld *Fach* breiter, dann lässt sich auch der Bereich für die *kompetenzbeschreibung* breiter ziehen. SchILD-NRW speichert Ihre Feldbreiten für die Zukunft.

:::

::: info Hinweis – Jahrgang und EP-Jahr getrennt erfassen

In SchILD-NRW 3 werden die Jahrgänge **01 und 02** und die **EP-Jahre E1, E2 und E3** getrennt erfasst. Folgen Sie [Die Jahre der Schuleingangsphase eintragen](/schild3/schueler/eintragung-der-ep-jahre-tutorial). Der ältere Hinweis unten verwendet E2 noch als Jahrgang und beschreibt einen früheren Korrekturweg über **Individualdaten II**. Übertragen Sie diesen Korrekturweg nicht auf die aktuelle Erfassung.

:::
