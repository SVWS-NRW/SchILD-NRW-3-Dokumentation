# Textzeugnisse für die Grundschule erstellen

Bereiten Sie Floskeln und Leistungsdaten für Textzeugnisse vor. Die Anleitung führt von Textbausteinen und Fachbemerkungen bis zum Zeugnisdruck.

Schließen Sie die [Vorbereitungen zur Erfassung von Leistungsdaten](/zeugnisse/grundschule/grundschulzeugnisse-vorbereitung-fuer-text-und-ankreuzzeugnisse-tutorial) in ihrer Schule ab.

## 1. Floskeln anlegen

[![Alle Floskelgruppen.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-floskelgruppen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-floskelgruppen.png)

*Alle Floskelgruppen.*

Neben den Noten werden in der Grundschule je nach Jahrgang auch Bemerkungen zu den Fächern, dem Leistungsstand und der Lernentwicklung auf dem Zeugnis ausgegeben.

Um diese bis einschließlich Jahrgang 3 zu erfassen und einheitlich zu formulieren, können in SchILD-NRW vorformulierte Textbausteine, sogenannte *Floskeln*, hinterlegt werden.

::: info Hinweis

Textbausteine können **Platzhalter** enthalten, die SchILD-NRW automatisch durch die Angaben zur Person ersetzt. Zum Beispiel wird *"$Vorname$"* durch den Vornamen und *"$Name$"* durch den Nachnamen ersetzt.

Außerdem können männliche und weibliche Formen über *&amp;männliche Form%weibliche Form&amp;* unterschieden werden.

:::

::: example Beispiel

*$Vorname$ hat sich in Konfliktsituationen als &amp;Streitschlichter%Streitschlichterin&amp; hervorgetan.*

wird zu

*Amani hat sich in Konfliktsituationen als Streitschlichterin hervorgetan.*

:::

Floskeln sind in *Gruppen* sortiert. Die Gruppe *AUE* enthält etwa die Floskeln zum *Außerunterrichtlichen Engagement* und *FACH* die *Fachbezogenen* Floskeln.

Die Floskeln stehen dann je nach Kontext zur Verfügung. Werden zum Beispiel *Zeugnisbemerkungen* eingegeben, stehen nur die Floskeln dieser Gruppe zur Auswahl.

[![Hinzufügen einer Floskeln zum Arbeits- und Sozialverhalten.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-hinzufuegen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-hinzufuegen.png)

*Hinzufügen einer Floskeln zum Arbeits- und Sozialverhalten.*

Öffnen Sie den Floskeleditor über *Kataloge* ➜ **"Floskeln" bearbeiten**.

Es ist die `Gruppe` zu wählen, zu der eine Floskel gehört.

Weiterhin muss ein in der Datenbank *eindeutiges* **Kürzel** vergeben werden.

Geben Sie den **Floskeltext**, falls gewünscht mit den entsprechenden Platzhaltern, ein.

Diese Floskel kann nun verwendet werden.

[![Eingabe von Fachbezogenen Floskeln, bei denen auch noch Fach, Jahrgang und Niveau als Filterbedingung angegeben werden.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-hinzufuegen-fachbezogen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-hinzufuegen-fachbezogen.png)

*Eingabe von Fachbezogenen Floskeln, bei denen auch noch Fach, Jahrgang und Niveau als Filterbedingung angegeben werden.*

Bei Floskeln zu *Fördermaßnahmen* und bei *Fachbezogenen Floskeln* ist noch ein **Fach** anzugeben, für das die Floskel gilt. Bei den *Fachbezogenen Floskeln* ist weiterhin noch der **Jahrgang** zu definieren und es kann noch ein **Niveau** festgelegt werden.

Auch während der Eingabe kann hier schon auf diese Felder gefiltert werden.

Einen gesetzten Filter können Sie entfernen, indem Sie den Eintrag im Feld *markieren* und dann die `Entf`-Taste drücken.

### Import und Export

[![Über den Schalter Import kann eine Excel-Datei mit Vorlagen ausgewählt werden. Hier im Screenshot wird der Import von Ankreuzkompetenzen gezeigt, das Importieren von Textbausteinen funktioniert jedoch analog.](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-import.png)](/bilder/grundschule/tutorials-gs-ankreuzzeugnisse-import.png)

*Über den Schalter **Import** kann eine Excel-Datei mit Vorlagen ausgewählt werden. Hier im Screenshot wird der Import von Ankreuzkompetenzen gezeigt, das Importieren von Textbausteinen funktioniert jedoch analog.*

Wenn Sie eine Excel-Datei mit vorbereiteten Textbausteinen haben, klicken Sie auf **Import** und wählen diese Datei aus. Danach stehen die importierten Floskeln in SchILD-NRW zur Verfügung.

Die hier verwendete Datei wurde im Zeugnisbereich auf der Seite des [MSB für Schulverwaltungssoftware](<https://www.svws.nrw.de>) heruntergeladen. An gleicher Stelle finden Sie ebenfalls eine leere Excel-Datei, die für das Befüllen mit eigenen Einträgen vorbereitet wird.

Entsprechend können Floskeln zur Weitergabe und -verarbeitung auch **exportiert** werden.

Klicken Sie hierzu auf `Export` und wählen Sie einen Dateispeicherort.

::: tip Tipp

Für einen weiteren Jahrgang müssen Sie die Textbausteine nicht vollständig neu eingeben: Exportieren Sie die vorhandenen Einträge, kopieren Sie die benötigten Zeilen in einem Tabellenkalkulationsprogramm und passen Sie den Jahrgang an. Speichern Sie die bearbeitete Datei und importieren Sie sie anschließend wieder in SchILD-NRW.

:::

::: warning Wichtig

Bitte beachten Sie, dass Floskeln - selbst erstellt oder als Import - nicht einfach verwendet werden können. Die Formulierungen müssen in den entsprechenden Fach- und Schulkonferenzen genehmigt werden.

:::

::: info Hinweis

- Fachfloskeln werden für den Jahrgang *E3* nicht eingegeben. Hier werden die Floskeln des Jahrgangs *E2* verwendet.
- Sie können Floskeln mit einem Doppelklick direkt in das Textfenster übernehmen.
- Wenn das *Kürzel* mit einem **\#** beginnt, kann eine Floskel auch über das Eintippen *"#KÜRZEL"* eingegeben werden.
- Bei der Eingabe von Floskeln kann der Haken bei **Mehrfache Nennung des Vornamens vermeiden** gesetzt werden. Das erste Vorkommen des Platzhalters *\$Vorname\$* wird dann zum Vornamen, folgende Nennungen werden zu *er* oder *sie*.

:::

## 2. Zeugnisse herunterladen

Laden Sie die Textzeugnisse herunter und legen Sie diese im SVWS-Arbeitsverzeichnis ab, wie es im Artikel zur Vorbereitung des Zeugnisdrucks beschrieben ist.

[![Aktivieren von Zieldifferentem Lernen für die Textzeugnisse.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-zieldifferentes-lernen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-zieldifferentes-lernen.png)

*Aktivieren von Zieldifferentem Lernen für die Textzeugnisse.*

::: info Hinweis

Das Hybridzeugnis kann für Schülerinnen und Schüler aus der Jahrgangsstufe 4, die zieldifferent unterrichtet werden, genutzt werden.

Dazu muss in SchILD die Auswahl **zieldifferentes Lernen** unter *Schüler* ➜ **Individual-Daten II** aktiviert sein.

:::

## 3. Eingabe von Floskeln

### Fachleistungen

[![In den lLeistungsdaten werden einmal die Noten eingegeben. Die Fachbezogenen Bemerkungen werden über eine Doppelklick in der Spalte Fachbez. Leistungsentw. jedem Fach hinzugefügt.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-floskeln-nutzen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-floskeln-nutzen.png)

*In den lLeistungsdaten werden einmal die Noten eingegeben. Die Fachbezogenen Bemerkungen werden über eine Doppelklick in der Spalte **Fachbez. Leistungsentw.** jedem Fach hinzugefügt.*

Gehen Sie über *Schüler ➜ Akt. Halbjahr ➜ Leistungsdaten* zu der Tabelle mit den Fächern der Schüler.

Tragen Sie nun, sofern es diese gibt, die Noten ein.

::: info Hinweis

Diese Eintragungen werden in der Regel durch die Fachlehrkräfte vorgenommen.

:::

Klicken Sie dann mit einem Doppelklick in der Spalte **Fachbez. Leistungsentw.** auf *(WideMemo)* des entsprechenden Faches.

Es öffnet sich der Editor. Darin können Sie Bemerkungen frei eingeben oder vorbereitete Floskeln verwenden.

- Es ist die Eingabe von Hand möglich.
- Ein Doppelklick auf eine Floskel fügt diese hinzu.
- Schreiben Sie das *Kürzel* einer Floskel aus, wird dieses automatisch durch die entsprechende Floskel ersetzt (sofern unten *Texteingabe automatisch auf Floskeln überprüfen* gesetzt ist).

Nutzen Sie auch die Filteroptionen, um die angezeigten Floskeln einzuschränken.

::: tip Tipp

- Einen Zeilenumbruch erzeugen Sie mit `Shift + Enter`.
- Einen fehlerhaften Eintrag entfernen Sie im Editorfenster, indem er markiert wird, dann drücken Sie `Entf`.

:::

Die Notenerfassung mit GradeHub und WeNoM ist dem SVWS-Server zugeordnet. Einrichtung und Bedienung sind in der [SVWS-Dokumentation](https://doku.svws-nrw.de/) beschrieben; siehe auch [Noten mit GradeHub und WeNoM erfassen](/zeugnisse/noteneingabe).

### Bemerkungen

[![Weitere Bemerkungen können durch die Klassenleitung oder Beauftragte eingegeben werden.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-bemerkungen.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-bemerkungen.png)

*Weitere Bemerkungen können durch die Klassenleitung oder Beauftragte eingegeben werden.*

Unter Akt. Halbjahr Bemerkungen werden durch die Klassenleitung oder Schulleitung an oder nach der Zeugniskonferenz noch weitere Bemerkungen gesetzt.

Weitere Bemerkungen sind zu diesen Feldern möglich:

- **Arbeits- und Sozialverhalten**
- **Lern- und Leistungsfortschritt**
- **Außerunterrichtlichem Engagement**
- **Förderschwerpunkt**

Weiterhin werden im Zuge von Versetzungen oder auch zum Abschluss von Jahrgang 4 weitere Bemerkungen für das Zeugnis aufgenommen

- **Zeugnisbemerkungen**
- **Bemerkungen zur Versetzung**
- **Empfehlung für Fortsetzung der Schullaufbahn**

::: info Hinweis

**Lern- und Leistunggstand**: Eingaben bei den grundsätzlichen Angaben zur *Lernentwicklung und zum Leistungsstand* haben bei der Zeugnisgenierung Vorrang vor den fachbezogenen Eingaben.

Wenn Sie also zu jedem Fach einen eigenen Bemerkungstext eingeben wollen, so muss dies beim jeweiligen Fach auf dem Karteireiter "Leistungsdaten" erfolgen. Somit wird dann bei *Lern- und Leistungsfortschritt* nichts mehr eingegeben.

Soll der Lern- und Leistungsstand zusammenfassend für alle Fächer auf dem Zeugnis ausgeben werden, sind die Fachbezogenen Bemerkungen frei zu lassen und die Zusammenfassung wird über *Lern- und Leistungsfortschritt* erfasst. Hier lassen sich natürlich auch passende Floskeln definieren und verwenden.

:::

Weiterhin wird der Bereich zum **Arbeits- und Sozialverhalten** auf dem Zeugnis nur ausgegeben, wenn auch eine Bemerkung hierzu gesetzt wurde.

Das Feld **Empfehlung für Fortsetzung der Schullaufbahn** wird ab dem 1. Halbjahr von Jahrgang 4 verwendet, um weitere Informationen zur *Übergangsempfehlung* für den Jahrgang 5 auszugeben.

## Weitere Ausgaben

[![Versetzungsvermerk im zweiten Halbjahr.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-versetzungsvermerk-akt-halbjahr.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-versetzungsvermerk-akt-halbjahr.png)

*Versetzungsvermerk im zweiten Halbjahr.*

Befindet sich eine Schule im 2. Halbjahr, wird auch der Versetzungsvermerk mit ausgegeben, der sich im Fuß des Reiters *Schüler ➜ Akt. Halbjahr* befindet.

[![Über die Schüler ➜ Individual-Daten II ➜ Grundschulbesuch wird die Übergangsempfehlung verwaltet.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-uebergangsempfehlung.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-uebergangsempfehlung.png)

*Über die Schüler ➜ Individual-Daten II ➜ Grundschulbesuch wird die Übergangsempfehlung verwaltet.*

Unter *Schüler ➜ Individual-Daten II* wird ab dem Zeugnis des 1. Halbjahres von Jahrgang 4 die **Übergangsempfehlungen** eingetragen.

Tragen Sie unter dem Bemerkungsfeld **Empfehlung für die Fortsetzung der Schullaufbahn** an dieser Stelle eine eventuelle Erläuterung ein.

### Ankreuzkompetenzen von ASV im Jahrgang 4

Mitunter wird das *Arbeits- und Sozialverhalten* im Jahrgang 4 über Ankreuzkompetenzen ausgegeben.

In diesem Fall wird das ASV nicht über einen Text erfasst, sondern über die Kompetenzen erfasst. Das *Hybridzeugnis* ist in der Lage, diese Situation bei Vorhandensein entsprechender Daten zu verarbeiten. Sollen weitere Ankreuzkompetenzen anderer Fächer ausgegeben werden, wäre das *Ankreuzzeugnis* zu verwenden.

Beachten Sie hierzu bitte die Steuerungsoptionen durch die *Zeugniseinstellungen.ini* aus dem Artikel zur Vorbereitung der Zeugnisse.

## 4. Zeugnisdruck

[![Drucken von Zeugnissen über die Reportverwaltung.](/bilder/grundschule/tutorials-gs-floskelzeugnisse-druck.png)](/bilder/grundschule/tutorials-gs-floskelzeugnisse-druck.png)

*Drucken von Zeugnissen über die Reportverwaltung.*

Drucken Sie die Zeugnisse über die Reportverwaltung.

Wählen sie hierzu die Klasse bzw. den Jahrgang im Schülercontainer aus, für die der Zeugnisdruck angestoßen werden soll.

Dann Doppelklicken Sie auf das entsprechende Zeugnisformular. Hier im Beispiel ist die *Dokumentenverwaltung* aktiv, wir erzeugen also einmal einen Druck der Zeugnisse auf dem Drucker und dann wird noch eine Kopie als .pdf bei dem jeweiligen Schüler abgelegt. Wichtig: Klicken Sie auf *die ganze Gruppe*, um die gesamte Gruppe zu verarbeiten.

Sind Sie nicht sicher, wie die Zeugnisse aussehen werden, wählen Sie *erst Vorschau*, um sich das beispielhafte Ergebnis anzusehen.

::: tip Tipp

Im allgemeinen Artikel zum Zeugnisdruck finden sich [typische Fehler](</einstieg/grundlagen/zeugnisvorbereitungen-und-zeugnisdruck-einfuehrung-in-schild-nrw#haufige-fehler-beim-zeugnisdruck>), die beim Druck auftreten können. Einige von diesen könnten auch in der Grundschule für Neudrucke sorgen.

:::
