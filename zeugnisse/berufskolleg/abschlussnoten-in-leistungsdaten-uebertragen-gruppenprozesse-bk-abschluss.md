# BK-Abschlussnoten in Leistungsdaten übertragen

Übertragen Sie die endgültig geprüften Abschlussnoten in die Leistungsdaten. Beachten Sie, dass bisherige Noten überschrieben und bei erneutem Holen der Leistungsdaten wiederum übernommen werden.

Wenn Sie die endgültigen Abschlussnoten unter **Schüler ➜ BK-Abschluss** geprüft und festgelegt haben, starten Sie den Gruppenprozess **Abschlussnoten in Leistungsdaten übertragen**.

::: info Hinweis

Die Abschlussnote überschreibt die bisherige **Note** unter **Schüler ➜ Akt. Halbjahr**. Weicht die bisherige Note davon ab, steht sie dort anschließend nicht mehr zur Verfügung.

Wenn Sie danach unter **BK-Abschluss** erneut **Leistungsdaten holen** ausführen, wird die neue Abschlussnote aus den Leistungsdaten geholt. Sie überschreibt dann auch die zuvor geholte Note im Reiter **BK-Abschluss**.

:::
