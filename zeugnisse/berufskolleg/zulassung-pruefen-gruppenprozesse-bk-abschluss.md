# Die Zulassung zu BK-Prüfungen prüfen

Starten Sie die Zulassungsberechnung für eine Schülergruppe, deren Prüfungsordnung eine entsprechende Zulassung vorsieht.

[![Prüfen Sie bei einer Schülergruppe, auf eine erreichte Zulassung.](/bilder/berufskolleg/gruppenprozesse-bk-zulassung-pruefen.png)](/bilder/berufskolleg/gruppenprozesse-bk-zulassung-pruefen.png)

*Prüfen Sie bei einer Schülergruppe, auf eine erreichte Zulassung.*

Starten Sie **Zulassung prüfen**. Der Gruppenprozess prüft die Zulassung nach dem vorgesehenen Verfahren. Unter **Schüler ➜ BK-Abschluss ➜ Zulassung** wird das Feld **Prüfung** auf **Ja** oder **Nein** gesetzt.

Es wird ein Protokoll der Prüfung angezeigt.

Sinnvolle Ergebnisse erhalten Sie in diesem Gruppenprozess nur, wenn eine Schülergruppe ausgewählt wurde, für die nach ihrer Prüfungsordnung eine Prüfung mit einer Zulassung vorgesehen ist.  

::: info Hinweis

Wird ein Abitur als Abschluss angestrebt, ist das Verfahren hierzu im Reiter *Schüler ➜ Abitur* durchführen.

:::
