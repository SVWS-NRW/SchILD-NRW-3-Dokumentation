# Leistungsdaten für die Abiturberechnung übernehmen

Übernehmen Sie die Leistungsdaten der Qualifikationsphase als ersten Schritt der Abiturberechnung. Bereits vorhandene Daten im Abiturbereich werden dabei überschrieben.

[![Starten von Leistungsdaten holen.](/bilder/sekundarstufen/gruppenprozesse-abitur-leistungsdaten-holen-1.png)](/bilder/sekundarstufen/gruppenprozesse-abitur-leistungsdaten-holen-1.png)

*Starten von **Leistungsdaten holen**.*

Dieser Gruppenprozess bildet die Grundlage für alle weiteren Abitur-Gruppenprozesse und muss somit als Erstes durchgeführt werden.

Er bildet mit den Gruppenprozessen

- **Kurse algorithmisch markieren** und
- **Abitur-Zulassung berechnen**

einen Dreierblock, der zur Berechnung der Zulassung durchgeführt werden muss.

Liegen gegen Ende der Q2 alle Noten in den Leistungsdaten vor, so führt dieser Prozess dazu, dass alle Noten der ausgewählten Schülermenge für die weiteren Abiturberechnungen unter dem Karteireiter *"Abitur"* zur Verfügung stehen.  

[![Warnung vor dem Überschreiben vorhandener Leistungsdaten, inklusive eventuell schon eingetragener Prüfungsleistungen.](/bilder/sekundarstufen/gruppenprozesse-abitur-leistungsdaten-holen-2.png)](/bilder/sekundarstufen/gruppenprozesse-abitur-leistungsdaten-holen-2.png)

*Warnung vor dem Überschreiben vorhandener Leistungsdaten, inklusive eventuell schon eingetragener Prüfungsleistungen.*

::: warning Wichtig

Dort schon vorhandene Daten werden überschrieben.

:::

::: tip Tipp

Wenn Sie später die Leistungsdaten einer einzelnen Person ändern, können Sie deren Abiturdaten auch einzeln aktualisieren. Öffnen Sie dazu **Abitur** und klicken Sie auf **Leistungsdaten holen**.

:::
