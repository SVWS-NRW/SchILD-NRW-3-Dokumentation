# Abiturdaten als Textdatei exportieren

Erstellen Sie AbiturExport.txt im gewählten Zielordner. Für jedes Abiturfach wird eine eigene Datenzeile ausgegeben.

[![Exportieren Sie die Abiturdaten in eine Textdatei über Verwaltung ➜ Export ➜ Abiturdaten.](/bilder/sekundarstufen/verwaltung-export-abiturdaten.png)](/bilder/sekundarstufen/verwaltung-export-abiturdaten.png)

*Exportieren Sie die Abiturdaten in eine Textdatei über Verwaltung ➜ Export ➜ **Abiturdaten**.*

Über *Verwaltung ➜ Export* ➜ **Abiturdaten** lässt sich eine Textdatei mit den Daten zum aktuellen Abitur erzeugen.

Hierzu ist ein **Ausgabeverzeichnis** zu wählen.

Klicken Sie dann auf `Daten exportieren`. Hierbei werden existierende Daten überschrieben, die diesbezügliche Meldung ist mit `OK` zu bestätigen.  

In diesem Ordner wird eine Datei *AbiturExport.txt* erzeugt, in der die Kopfzeile wie folgt aussieht und damit in den Folgezeilen auch die entsprechenden Informationen enthält.

     SchulNR;SchuelerNr;Geschlecht;Fach;Kursart;Fremdspr_fortgef;Vornote;PruefNote;AbiNote;Bestanden;PruefOrdn;SGL

Es wird für jedes Abiturfach eine eigene Zeile erzeugt.
