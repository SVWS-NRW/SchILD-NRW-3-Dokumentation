# Das eigene Kennwort ändern

Ändern Sie das Kennwort des aktuell angemeldeten Benutzers. Geben Sie zuerst das bisherige und anschließend zweimal das neue Kennwort ein.

[![Ändern des eigenen Kennworts über Verwaltung ➜ Benutzer.](/bilder/benutzer-einstellungen/verwaltung-kennwort-aendern.png)](/bilder/benutzer-einstellungen/verwaltung-kennwort-aendern.png)

*Ändern des eigenen Kennworts über Verwaltung ➜ Benutzer.*

Mit dem Knopf *Verwaltung ➜ Benutzer* ➜ **Kennwort ändern** kann ein eingeloggter Benutzer das eigene Kennwort ändern.

1. Geben Sie das bisherige Kennwort ein.
2. Geben Sie das neue Kennwort zweimal ein.

Bestätigen Sie mit **OK**.

::: danger Achtung

Wählen Sie modernen Standards entsprechende Kennwörter.

:::
