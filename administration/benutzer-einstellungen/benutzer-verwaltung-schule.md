# Benutzerfunktionen aufrufen

Öffnen Sie die Benutzerverwaltung, ändern Sie Ihr eigenes Kennwort oder zeigen Sie die aktuell angemeldeten Datenbankbenutzer an.

[![Die Optionen unter Verwaltung ➜ Benutzer.](/bilder/benutzer-einstellungen/verwaltung-benutzer.png)](/bilder/benutzer-einstellungen/verwaltung-benutzer.png)

*Die Optionen unter Verwaltung ➜ Benutzer.*

Über *Verwaltung Benutzer* stehen drei Untermenüs zur Verfügung:

- **Benutzerverwaltung:** Legen Sie Benutzer an und ordnen Sie ihnen über **Benutzergruppen** die passenden Berechtigungen zu.
- **Kennwort ändern**: Hiermit kann der *aktuelle Benutzer* das *eigene Kennwort* ändern.
- **Aktuelle Datenbanknutzer anzeigen** zeigt alle *aktuell eingeloggten Benutzer* an und seit wann sie angemeldet sind.
