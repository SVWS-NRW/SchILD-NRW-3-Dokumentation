# Angemeldete Datenbankbenutzer anzeigen

Prüfen Sie, welche Benutzer aktuell an der Datenbank angemeldet sind und seit wann ihre Anmeldung besteht.

[![Zeigen Sie alle aktuell eingeloggten Benutzer mit dem Login-Datum an.](/bilder/datenbanken/verwaltung-aktuelle-benutzer-anzeigen.png)](/bilder/datenbanken/verwaltung-aktuelle-benutzer-anzeigen.png)

*Zeigen Sie alle aktuell eingeloggten Benutzer mit dem Login-Datum an.*

Über *Verwaltung ➜ Benutzer* ➜ **Aktuelle Benutzer anzeigen** werden alle aktuell eingeloggten Benutzer mit ihrem Login-Datum angezeigt.

Schließen Sie das Fenster mit **OK**.
