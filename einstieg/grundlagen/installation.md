# Installation

Richten Sie zunächst SchILD-NRW 3 ein und stellen Sie anschließend die benötigten Reports und Zeugnisformulare bereit. Die folgenden Anleitungen führen durch die einzelnen Schritte.

## Installation von SchILD-NRW 3

SchILD-NRW 3 benötigt den SVWS-Server. Installieren Sie deshalb zuerst den Server und anschließend das Windows-Programm. Die Anleitung beschreibt die Einrichtung am Einzelplatz oder im Netzwerk sowie die Verbindung zur Datenbank.

[Zur Anleitung: SVWS-Server und SchILD-NRW 3 installieren](/administration/installation/installation-svws-server-und-schild-nrw-3)

## Installation der Basisreportsammlung

Die Basisreportsammlung enthält Vorlagen für Listen, Bescheinigungen und weitere Ausgaben. Sie wird bei der Erstinstallation mitgeliefert und lässt sich unabhängig vom Programm aktualisieren. Die Anleitung erklärt das Herunterladen und Bereitstellen der Sammlung sowie den Schutz eigener Anpassungen.

[Zur Anleitung: Die Basisreportsammlung herunterladen und aktualisieren](/reporting/basisreports/basisreportsammlung-herunterladen-und-aktualisieren)

## Installation von Zeugnisreports

Zeugnisreports werden als eigene Pakete für die jeweilige Schulform bereitgestellt. Laden Sie das passende Paket herunter und entpacken Sie es in die Reportstruktur. Die Anleitung zeigt, wo die Formulare abgelegt werden und wie sie in der Reportverwaltung verfügbar werden.

[Zur Anleitung: Zeugnisformulare herunterladen und bereitstellen](/reporting/zeugnisformulare/zeugnisformulare-herunterladen-und-aktualisieren)
